# Claude Session Brief — career

아래 내용을 `career/` 작업 중인 Claude 세션에 그대로 붙여넣으면 된다.

```text
이 작업은 자기소개서/이력서 작성을 세션 기억에 의존하지 않고 파일 기반으로 관리하는 방식으로 진행해줘.

먼저 아래 파일을 순서대로 읽어:
1. CLAUDE.md
2. PROJECT_STATUS.md
3. base/MASTER_PROFILE.md
4. base/NON_NEGOTIABLE_RULES.md
5. base/APPLICATION_MODEL.md
6. base/BASE_STRATEGY_QUESTIONS.md
7. base/REQUEST_ROUTING.md
8. base/QUESTION_STRATEGY_RULES.md
9. base/WRITING_RULES.md
10. base/STORY_BANK.md
11. base/ROLE_FIT_CHECKLIST.md
12. base/AGENT_WORKFLOW.md

지원 회사 폴더가 있으면 추가로:
13. applications/<회사>/SOURCES.md
14. applications/<회사>/DECISION_MEMO.md
15. applications/<회사>/JD_NOTES.md
16. applications/<회사>/STRATEGY.md
17. applications/<회사>/TARGET_COMPANY.md
18. applications/<회사>/REVISION_REQUEST.md
19. applications/<회사>/QUESTION_MAP.md
20. applications/<회사>/writer_pack/05_ACTIVE_DRAFT.txt
21. applications/<회사>/REVISION_LOG.md

그 다음 아래 형식으로 답해:

작업 유형:
- base 정보 채우기 / JD 분석 / 초안 작성 / 초안 수정 중 하나

요청 라우팅:
- 요청 유형
- 가장 상위 영향 레이어
- 실행 체인

먼저 채워야 할 파일:
- 비어 있거나 부족한 파일이 무엇인지

판단 메모:
- 실제 업무가 무엇인지
- 회사가 어떤 방식으로 돈을 버는지
- 누가 왜 기꺼이 비용을 지불하는지
- AI 이후 약해질 부분과 남을 부분이 무엇인지
- 다른 회사와 비교해 이 회사가 전면에 두는 차별점이 무엇인지
- 최근 2025년 하반기 이후와 현재 연도 시그널이 무엇인지
- 왜 이 회사의 이 직무인지가 사업, 자산군, 방식 차원에서 설명되는지

전략 메모:
- 한 줄 전략
- 내 경험을 어떤 업무 언어로 번역할지
- 빼야 할 인상
- 내가 관심 있다고 말할 수 있는 구체 사업, 자산군, 운영 방식

사용할 사례:
- STORY_BANK에서 어떤 사례를 쓸지 2~3개 선택

문항별 설계:
- 각 질문이 증명해야 할 한 가지
- 질문별 주력 사례
- 질문끼리 겹치면 안 되는 포인트

작성 방향:
- 이번 지원서에서 강조할 역량
- 빼야 할 표현
- 문단 구조

규칙 준수 체크:
- 쉼표 남용 여부
- 내부 프로젝트명/파일명 제거 여부
- 독자 가정이 인사팀 기준인지
- 문항 간 중복 여부

주의사항:
- 없는 사실 추가 금지
- 기존 초안이 있으면 처음부터 다시 쓰지 말고 수정 우선
- 수치와 역할은 MASTER_PROFILE 기준으로만 사용
- 전략이 약하면 문장 수정 전에 QUESTION_MAP부터 다시 작성
- 복합 요청이면 먼저 REVISION_REQUEST와 REQUEST_ROUTING 기준으로 분류
```
