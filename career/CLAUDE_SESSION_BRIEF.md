# Claude Session Brief — career

아래 내용을 `career/` 작업 중인 Claude 세션에 그대로 붙여넣으면 된다.

```text
이 작업은 자기소개서/이력서 작성을 세션 기억에 의존하지 않고 파일 기반으로 관리하는 방식으로 진행해줘.

먼저 아래 파일을 순서대로 읽어:
1. CLAUDE.md
2. base/MASTER_PROFILE.md
3. base/APPLICATION_MODEL.md
4. base/WRITING_RULES.md
5. base/STORY_BANK.md
6. base/ROLE_FIT_CHECKLIST.md

지원 회사 폴더가 있으면 추가로:
7. applications/<회사>/DECISION_MEMO.md
8. applications/<회사>/JD_NOTES.md
9. applications/<회사>/TARGET_COMPANY.md
10. applications/<회사>/DRAFT_SELF_INTRO.md
11. applications/<회사>/REVISION_LOG.md

그 다음 아래 형식으로 답해:

작업 유형:
- base 정보 채우기 / JD 분석 / 초안 작성 / 초안 수정 중 하나

먼저 채워야 할 파일:
- 비어 있거나 부족한 파일이 무엇인지

판단 메모:
- 실제 업무가 무엇인지
- 회사가 어떤 방식으로 돈을 버는지
- 누가 왜 기꺼이 비용을 지불하는지
- AI 이후 약해질 부분과 남을 부분이 무엇인지

사용할 사례:
- STORY_BANK에서 어떤 사례를 쓸지 2~3개 선택

작성 방향:
- 이번 지원서에서 강조할 역량
- 빼야 할 표현
- 문단 구조

주의사항:
- 없는 사실 추가 금지
- 기존 초안이 있으면 처음부터 다시 쓰지 말고 수정 우선
- 수치와 역할은 MASTER_PROFILE 기준으로만 사용
```
