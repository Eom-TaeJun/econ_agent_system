# /apply — career 문서 작성 시작

## 읽을 파일

1. `base/MASTER_PROFILE.md`
2. `base/APPLICATION_MODEL.md`
3. `base/WRITING_RULES.md`
4. `base/STORY_BANK.md`
5. `base/ROLE_FIT_CHECKLIST.md`

지원 회사 폴더가 있으면 추가로:

6. `applications/<회사>/DECISION_MEMO.md`
7. `applications/<회사>/JD_NOTES.md`
8. `applications/<회사>/TARGET_COMPANY.md`
9. `applications/<회사>/DRAFT_SELF_INTRO.md`

## 해야 할 일

1. 사실 파일이 비어 있는지 확인한다
2. 실제 업무와 수익구조가 정리된 판단 메모가 있는지 확인한다
3. 이번 작업이 아래 중 무엇인지 분류한다
   - base 정보 채우기
   - JD 분석
   - 초안 작성
   - 초안 수정
4. 새로 써야 할지, 기존 초안을 수정해야 할지 판단한다
5. 사용할 story 후보를 2~3개 고른다

## 출력 형식

```text
작업 유형: 초안 수정
먼저 읽을 파일:
- base/MASTER_PROFILE.md
- base/APPLICATION_MODEL.md
- base/STORY_BANK.md
- applications/<회사>/DECISION_MEMO.md
- applications/<회사>/TARGET_COMPANY.md
- applications/<회사>/DRAFT_SELF_INTRO.md

판단 메모:
- 실제 업무:
- 수익구조:
- AI 이후 유지되는 부분:

사용할 사례:
- Story 01
- Story 03

주의:
- 없는 사실 추가 금지
- 기존 초안 무시하고 처음부터 다시 쓰지 말 것
```
