# /question — Question Planner

## 목적

`QUESTION_MAP.md`를 채워 문항별 역할, 사례, 금지 중복을 정리하고, STRATEGY.md의 구체 지침을 Draft Writer에게 전달하는 "전략 → 초안 전달 체크리스트"를 함께 작성한다.

## 읽을 파일

1. `base/QUESTION_STRATEGY_RULES.md`
2. `applications/<회사>/STRATEGY.md`
3. `applications/<회사>/TARGET_COMPANY.md`
4. `applications/<회사>/QUESTION_MAP.md`
5. 문항 원문

## 해야 할 일

1. 각 문항의 평가 포인트를 뽑는다.
2. 각 문항이 증명할 한 가지를 적는다.
3. 문항별 주력 사례를 배정한다.
4. 다른 문항과 겹치면 안 되는 점을 적는다.
5. 내부 용어를 바꿔 쓸 업무 언어를 적는다.
6. **STRATEGY.md에서 아래 항목을 뽑아 "전략 → 초안 전달 체크리스트"를 작성한다:**
   - 초안에 반드시 녹일 회사 언어
   - 경험별 번역 지침
   - 초안에서 피할 방향
   - 전면 역량 vs 보조 역량
   - 자가 점검 체크박스

## 출력 형식

```text
역할: Question Planner

질문 1:
- 증명할 한 가지:
- 주력 사례:
- 금지 중복:

질문 2:
- 증명할 한 가지:
- 주력 사례:
- 금지 중복:

전략 → 초안 전달 체크리스트:
- 녹일 회사 언어:
- 경험별 번역 지침:
- 피할 방향:
- 전면 vs 보조:
```
