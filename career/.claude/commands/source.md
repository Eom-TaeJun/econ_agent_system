# /source — Source Collector

## 목적

공식 소스, 현업 인터뷰, 직무 발행 리포트, 업계 뉴스를 다채널로 수집해 `SOURCES.md`를 채운다.

## 읽을 파일

1. `base/BASE_STRATEGY_QUESTIONS.md`
2. `applications/<회사>/SOURCES.md`

## 수집 순서

### Phase 1. 공식 채널 (채용 공고 + 회사 사이트 + IR)

1. 채용 공고 원문을 WebFetch로 확보한다.
2. 회사 메인, 소개, 비전, CEO 메시지를 WebFetch로 확인한다.
3. DART 사업보고서, 실적보고서를 WebFetch/WebSearch로 확인한다.
4. 공식 리서치 채널, 리포트 채널이 있는지 WebSearch로 확인한다.

### Phase 2. 현업 인터뷰 수집

1. 공식 채용 페이지에 직무 인터뷰가 있는지 확인한다.
2. WebSearch로 `"{회사명}" "{직무명}" 인터뷰`를 검색한다.
3. WebSearch로 `"{회사명}" "{직무명}" 현직자`를 검색한다.
4. WebSearch로 `"{회사명}" "{부서명}" 유튜브`를 검색한다.
5. 찾은 인터뷰에서 뽑을 것:
   - 일과 루틴
   - 실제 쓰는 도구와 언어
   - 조직 구조와 handoff
   - 성장 경로
   - 이 직무가 중요하게 보는 것

### Phase 3. 직무 발행 리포트 / 코멘터리

1. WebSearch로 `"{회사명}" "{직무 관련 키워드}" 리포트 OR 코멘터리 OR 전략`을 검색한다.
2. 회사 공식 리서치 채널에서 해당 직무가 발행한 자료를 확인한다.
3. 찾은 리포트에서 뽑을 것:
   - 실제 쓰는 분석 프레임과 언어
   - 시장을 읽는 방식
   - 강조하는 지표와 관점

### Phase 4. 업계 뉴스 / 대외 인정

1. WebSearch로 `"{회사명}" 최근 6개월` 관련 뉴스를 검색한다.
2. WebSearch로 `"{회사명}" 수상 OR 선정 OR 인정 {연도}`를 검색한다.
3. 경쟁사 대비 차별점이 보이는 기사를 표시한다.

### Phase 5. 경쟁사 비교

1. 같은 업권 주요 경쟁사 2~3곳을 정한다.
2. WebSearch로 경쟁사 같은 직무의 채용 공고나 조직 구조를 확인한다.
3. 이 회사만의 차별점과 약점을 정리한다.

### Phase 6. 커뮤니티 / 후기

1. WebSearch로 `"{회사명}" "{직무명}" 후기 OR 면접`을 검색한다.
2. 신뢰도를 표시한다 (공식 > 실명 기사 > 익명 커뮤니티).

## 수집 완료 기준

- `SOURCES.md` 상단 수집 상태 표에서 빈 칸이 3개 미만이어야 한다.
- 현업 인터뷰가 최소 1개 이상 확보돼 있어야 한다.
- 직무 발행 리포트가 최소 1개 이상 확인돼 있어야 한다 (없으면 "해당 없음 확인"으로 표시).
- 최근 6개월 내 시그널이 최소 2개 이상 있어야 한다.
- 공식 소스와 외부 정보가 충돌하면 메모돼 있어야 한다.

```text
완료 판정: O/X

핵심 발견:
- 현업 인터뷰에서 뽑은 실제 언어:
- 직무 리포트에서 뽑은 분석 프레임:
- 경쟁사 대비 차별점:
- 가장 강한 최근 시그널:

- Signal Analyst 입력용 핵심 사실:
- Strategy Designer 입력용 차별화 근거:
```
