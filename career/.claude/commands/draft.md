# /draft — Draft Writer

## 목적

`STRATEGY.md`와 `QUESTION_MAP.md`를 바탕으로 `writer_pack/05_ACTIVE_DRAFT.txt`를 작성하거나 수정한다.

## 읽을 파일

1. `base/NON_NEGOTIABLE_RULES.md`
2. `base/WRITING_RULES.md`
3. `applications/<회사>/STRATEGY.md`
4. `applications/<회사>/QUESTION_MAP.md`
5. `applications/<회사>/writer_pack/05_ACTIVE_DRAFT.txt`

## 해야 할 일

1. `STRATEGY.md`를 먼저 읽고 아래를 확인한다:
   - 회사/직무 언어 (초안에 녹여야 할 구체 용어)
   - 경험별 번역 지침 (원래 서사 → 직무 언어 변환)
   - 피할 방향과 빼야 할 인상
   - 전면 역량 vs 보조 역량
2. `QUESTION_MAP.md`가 충분한지 확인한다.
3. `QUESTION_MAP.md` 하단의 "전략 → 초안 전달 체크리스트"를 확인한다.
4. 문항별 의도에 맞게 초안을 쓴다.
5. 파일명과 내부 명칭을 제거한다.
6. 같은 결론과 같은 장면 반복이 없는지 확인한다.
7. 아래 전략 대조를 수행한다.

## 전략 대조 (초안 완료 후 필수)

- [ ] STRATEGY.md의 회사 언어가 초안에 최소 1회 이상 등장하는가
- [ ] 경험별 번역 지침대로 표현이 바뀌었는가
- [ ] 피할 방향에 해당하는 문장이 없는가
- [ ] 보조 역량이 전면 역량보다 부각되지 않았는가

## 출력 형식

```text
역할: Draft Writer

전략 확인:
- STRATEGY.md 핵심: (한 줄 전략 요약)
- 녹일 회사 언어: (구체 용어 나열)
- 피할 방향: (요약)

작성 전 체크:
- QUESTION_MAP 작성 여부:
- 전략 전달 체크리스트 유무:
- 규칙 위반 가능성:

초안 방향:
- 질문 1:
- 질문 2:
- 질문 3:

전략 대조 결과:
- 회사 언어 반영: O/X (구체 위치)
- 번역 지침 반영: O/X (구체 위치)
- 피할 방향 위반: O/X
- 역량 비중 적절: O/X
```
