# Writer Pack

이 폴더는 `이 폴더만 읽어도 초안을 쓸 수 있는` 회사별 자기소개서 패키지다.

## 읽는 순서

1. `00_READ_FIRST.md`
2. `01_COMPANY_ROLE.md`
3. `02_MY_SOURCE.md`
4. `03_MY_INTERPRETATION.md`
5. `04_EXAMPLES.md`
6. `05_ACTIVE_DRAFT.txt`

## 작성 규칙

- 실제 자기소개서 본문은 항상 `05_ACTIVE_DRAFT.txt`에만 쓴다.
- `v2`, `v3`, `최종수정본` 같은 새 초안 파일을 만들지 않는다.
- 회사 정보 변경은 `01_COMPANY_ROLE.md`부터 고친다.
- 내 사례 변경은 `02_MY_SOURCE.md`부터 고친다.
- 사람상과 문단 구조 변경은 `03_MY_INTERPRETATION.md`부터 고친다.
- 좋은 문장 예시 변경은 `04_EXAMPLES.md`에 모은다.

## 목적

- 다른 AI가 이 폴더만 보고도 바로 초안을 작성하거나 수정할 수 있게 한다.
- 회사, 내 소스, 내 해석, 예시, 현재 초안을 한 곳에 묶는다.
