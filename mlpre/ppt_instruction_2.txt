[슬라이드 1] 지난 시간 복습: 편향과 분산
핵심 포인트:
- 높은 편향 = 과소적합 (모델이 너무 단순)
- 높은 분산 = 과적합 (노이즈까지 학습)
- 총 오차 = 편향² + 분산 + 줄일 수 없는 노이즈
하단 한 줄: 오늘 다룰 모든 알고리즘은 이 식의 어느 항을 줄이느냐로 분류된다

[슬라이드 2] 오늘의 로드맵
핵심 포인트:
- 1단계: 결정 트리 — 앙상블의 기본 부품
- 2단계: 배깅 / Random Forest — 병렬로 분산 감소
- 3단계: 부스팅 — 순차적으로 편향 감소
하단 한 줄: 같은 트리를 쓰지만 무엇을 줄이느냐가 다르다

[슬라이드 3] 결정 트리란 무엇인가
핵심 포인트:
- 이진 분할 반복: "조건이 참 → 왼쪽, 거짓 → 오른쪽"
- 구조: 루트 노드 / 내부 노드 / 리프 노드
- CART: 분류(다수 클래스) + 회귀(평균값) 모두 처리
- 강점: 구조 시각화 가능 → 비전문가에게 결과 설명 가능
하단 한 줄: scikit-learn의 DecisionTreeClassifier / Regressor 모두 CART

---

[슬라이드 4] 이진 분할 기준 — 무엇으로 나눌 것인가
핵심 포인트:
- CART: 모든 특성 × 모든 분할 위치 탐색 → 불순도 감소 최대인 분할 선택
- Information Gain = 분할 전 불순도 − (왼쪽 불순도 × 비율 + 오른쪽 불순도 × 비율)
- 항상 이진 분할 → 여러 번 반복으로 세분화
오른쪽: IG 수식 강조 박스

---

[슬라이드 5] 불순도 측정 — Gini vs Entropy
핵심 포인트:
- Gini = 1 − Σpᵢ²   예: A=7/10, B=3/10 → 1−(0.49+0.09) = 0.42
- Entropy = −Σpᵢ log₂(pᵢ)   동일 예: ≈ 0.88
- 성능 차이 거의 없음. Gini가 log 없어서 빠름 → scikit-learn 기본값
- 회귀 트리는 MSE 사용
왼쪽: Gini 수식 / 오른쪽: 수치 비교 예시

---

[슬라이드 6] 트리가 깊어질수록 일어나는 일
핵심 포인트:
- 깊을수록 훈련 데이터에 정확 → 극단적으로 리프 1개 = 샘플 1개
- 이것이 높은 분산의 전형 → 데이터 조금 달라지면 구조 완전히 변함
- 원인: 탐욕적 분할 (현재 최선만 보고 나중을 고려 안 함)
하단 한 줄: 훈련 정확도 100%가 오히려 경고 신호

---

[슬라이드 7] 가지치기 — 복잡도를 제어하다
핵심 포인트:
- 사전 가지치기: max_depth / min_samples_split / min_samples_leaf
- 사후 가지치기: 완전히 키운 후 성능에 기여 없는 가지 제거
- 한계: 단일 트리는 여전히 높은 분산 → 앙상블로 해결
하단 한 줄: 가지치기는 증상 완화, 앙상블이 근본 해결

---

[슬라이드 8] 앙상블 — 혼자보다 함께
핵심 포인트:
- 핵심 조건: 다양성 (같은 방향으로 틀리면 효과 없음)
- 배깅: 다른 데이터로 병렬 학습 → 분산 감소
- 부스팅: 오차 전달하며 순차 학습 → 편향 감소
- 스태킹: 여러 모델 예측을 새 특성으로 메타 학습 (오늘은 미다룸)
하단 한 줄: 다양성의 방향이 전략을 결정한다

---

[슬라이드 9] 배깅의 수학 — 왜 분산이 줄어드는가
핵심 포인트:
- 독립 변수 n개 평균의 분산: σ²/n → n 클수록 줄어든다
- 현실: 트리들은 독립적이지 않음 → 상관 ρ 존재
- 실제 분산: ρσ² + (1−ρ)σ²/n
- ρ 클수록 첫 항이 지배 → 상관 낮추는 것이 핵심
중앙: 두 수식 나란히 강조 박스

---

[슬라이드 10] Bootstrap — 복원 추출
핵심 포인트:
- N개에서 N개를 복원 추출 → 어떤 샘플은 중복, 어떤 건 미선택
- 선택될 확률: 1 − (1−1/n)ⁿ → n→∞ 시 1−1/e ≈ 63.2%
- OOB 샘플: 선택 안 된 36.8% → 내장 검증에 활용
오른쪽: 복원 추출 도식 (원본 → 서브셋 × k)

---

[슬라이드 11] Random Forest — 배깅 + 특성 무작위성
핵심 포인트:
- 배깅만 쓰면 강한 특성이 모든 트리 상위에 나타남 → 트리 간 상관 ρ 높아짐
- RF: 각 분할마다 p개 중 m개만 무작위 선택 (분류: √p, 회귀: p/3)
- 강한 특성이 배제될 기회 → ρ 낮아짐 → 앙상블 효과 커짐
- 출력: 분류=다수결, 회귀=평균
하단 한 줄: 무작위성이 다양성을 만들고, 다양성이 성능을 만든다

---

[슬라이드 12] OOB Error — 내장 검증
핵심 포인트:
- 각 트리가 사용하지 않은 OOB 샘플로 해당 트리 예측 성능 평가
- OOB Error = 전체 OOB 예측 집계 오차
- 별도 데이터 분할 없이 교차 검증과 동일한 역할
- scikit-learn: oob_score=True
하단 한 줄: 학습이 끝나면 자동으로 검증 지표가 따라온다

---

[슬라이드 13] 왜 배깅은 분산을, 부스팅은 편향을 줄이는가
왼쪽 — 배깅:
- 깊은 트리 = 낮은 편향 + 높은 분산
- 독립 학습 후 평균 → 오차 상쇄 → 분산 감소
- 편향은 그대로 유지
오른쪽 — 부스팅:
- 얕은 트리 = 높은 편향 + 낮은 분산
- 이전 오차에 집중해 순차 학습 → 편향 감소
- 과도한 라운드 → 분산 증가 (학습률로 제어)
하단 안내 박스: 노이즈 많은 데이터 → 배깅 / 노이즈 적고 품질 높은 데이터 → 부스팅

---

[슬라이드 14] 부스팅의 직관 — 오답 노트
핵심 포인트:
- 1라운드: 전체 학습 → 맞춘 것 + 틀린 것 구분
- 2라운드: 틀린 부분에 집중 → 1라운드 보완
- 3라운드~: 누적 예측의 부족한 부분 반복 보완
- 최종: 모든 약한 학습기의 가중합산
하단 한 줄: 각 학습기는 약하지만 서로 다른 부분을 커버한다

---

[슬라이드 15] AdaBoost — 가중치와 지수 손실
핵심 포인트:
- 틀린 샘플 가중치 ↑, 맞춘 샘플 가중치 ↓ → 다음 학습기가 어려운 것에 집중
- 각 학습기의 앙상블 기여도 = 정확도에 비례
- 손실 함수: L = exp(−y × f(x)) → 지수 손실 → 이상치에 민감
- 기본 학습기: 깊이 1 결정 트리 (Decision Stump)
오른쪽: 지수 손실 수식 강조 박스

---

[슬라이드 16] Gradient Boosting — 잔차와 경사 하강
상단 맥락: AdaBoost는 가중치로 오차를 표현 → GBM은 잔차 자체를 학습 대상으로
핵심 포인트:
- 잔차 r₁ = y − F₀(x) → h₁이 r₁을 학습 → F₁ = F₀ + η × h₁
- 왜 경사 하강인가: MSE에서 ∂L/∂F = −(y−F) → 잔차 = 손실의 음의 기울기
- 장점: 손실 함수를 임의로 교체 가능 (MSE/로그손실/MAE)
- η(학습률): 작으면 일반화↑ 느림 / 크면 빠름 과적합 위험
중앙: 잔차=기울기 연결 수식 강조 박스

---

[슬라이드 17] XGBoost — 2차 근사와 정규화
핵심 포인트:
- 1차 개선: 2차 미분(헤시안)까지 사용 → Newton's method → 수렴 빠름
- 2차 개선: 목적함수에 정규화 항 추가 L = Σloss + Ω(트리복잡도)  Ω = γ×리프수 + λ×Σ(리프가중치²)
- 속도: 특성 미리 정렬 + 병렬 처리
- LightGBM: 레벨 방향 → 리프 방향 성장 → 대용량에서 더 빠름
오른쪽: 목적함수 수식 강조 박스

---

[슬라이드 18] 배깅 vs 부스팅 — 비교 표
4열 비교 테이블:

항목         | 배깅              | AdaBoost       | GBM / XGBoost
학습 방향    | 병렬, 독립        | 순차, 의존     | 순차, 의존
줄이는 것    | 분산              | 편향           | 편향
기본 학습기  | 깊은 트리         | 결정 스텀프    | 얕은 트리
손실 함수    | Gini / MSE        | 지수 손실      | 임의 미분가능
출력         | 다수결 / 평균     | 클래스 / 확률  | 클래스 / 확률 / 연속값
적합 데이터  | 노이즈 많은 데이터| 안정적 데이터  | 품질 높은 구조적 데이터

[슬라이드 19] 특성 중요도 — 모델이 알려주는 신호
핵심 포인트:
- 불순도 기반: 특성이 분할에 쓰일 때마다 불순도 감소량 집계 → 합산
- 주의: 상관 높은 특성이 여럿이면 중요도 분산됨
- Permutation Importance: 특성 하나 무작위 섞고 성능 저하 측정 → 더 신뢰 가능
- 주의: 중요도 높음 ≠ 인과적 중요 (1차시 복습)
하단 한 줄: 예측에 중요한 신호와 원인은 다르다

---

[슬라이드 20] 어떤 모델을 언제 선택하는가
3단 의사결정 구조:
- 빠른 베이스라인 필요 → Random Forest (튜닝 없이도 안정적, 스케일링 불필요)
- 최고 성능 목표 → XGBoost / LightGBM (대용량이면 LightGBM, 튜닝 필요)
- 해석 가능성 우선 → 단일 결정 트리 (max_depth 3~5, 비전문가 설명 가능)
하단 안내 박스: 비정형(이미지/텍스트/음성) → 딥러닝 / 정형 테이블 → 트리 기반 앙상블

[슬라이드 21] 앙상블의 본질 — 다양성이 힘이다
핵심 포인트:
- 같은 방향으로 틀리는 100개 = 크게 틀린 1개
- 배깅: 데이터 샘플링 + 특성 무작위성 → 분산 감소
- 부스팅: 오차 집중 학습 → 편향 감소
- 스태킹: 여러 종류 모델 혼합 → 더 풍부한 다양성 (추후 다룸)
하단 한 줄: 서로 다른 방식으로 틀리는 모델의 결합이 더 강하다

[슬라이드 22] 오늘의 정리
핵심 포인트:
- 결정 트리: 이진 분할 반복, CART(Gini/MSE), 높은 분산이 약점
- 배깅/RF: Bootstrap + 병렬 학습 → σ²/n 원리로 분산 감소, 특성 무작위성으로 ρ 낮춤
- AdaBoost: 지수 손실 + 가중치 조정 → 편향 감소
- GBM/XGBoost: 잔차=기울기 → 임의 손실 최적화, 2차 근사 + 정규화
하단 한 줄: 편향²+분산+노이즈 — 배깅은 분산 항을, 부스팅은 편향 항을 줄인다
