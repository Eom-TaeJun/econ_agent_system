STEP 2. 슬라이드 생성 (섹션별로 나눠서 입력)

아래 슬라이드들을 순서대로 만들어줘.
각 슬라이드는 제목 1줄 + 시각 요소 + 하단 핵심 메시지 바 구조를 따를 것.

[내용 구성 원칙]
- 이번 2차시의 핵심 주제는 "트리 모델 소개"가 아니라 "편향-분산 문제를 트리 기반 앙상블이 어떻게 해결하는가"이다.
- 각 슬라이드는 개별 알고리즘 설명보다 앞뒤 연결을 우선한다.
- 1차시의 핵심 개념인 일반화, 손실, 편향-분산과 반드시 연결해 설명할 것.
- 결정트리 파트는 앙상블로 넘어가기 위한 전제까지만 설명하고, 핵심 무게중심은 배깅 vs 부스팅 비교에 둘 것.
- 가능하면 하나의 공통 예시(예: 고객 이탈 예측 또는 대출 승인 예측)를 슬라이드 전반에 반복 사용해 설명 흐름을 통일할 것.

──── STEP 2-B: 결정 트리 (슬라이드 3~7) ────

[슬라이드 3 — 결정 트리란 무엇인가 + CART]

- 제목: "결정 트리란 무엇인가"

  · 리프 노드 4개(배경 #243660): "고위험" / "중위험" / "저위험" / "관찰"
  각 노드: 18pt, 연결선 #00C853

- 우측 45%: 세로로 4개 레이블 박스

  각 박스: 배경 #243660

[슬라이드 4 — 이진 분할 기준: Information Gain]
레이아웃: 중앙 흐름 + 수식 + 시각 예시
- 제목: "어떻게 나눌 곳을 정하는가 — Information Gain"
- 중앙 상단: 가로 3단 흐름 (화살표)
  · "모든 특성 × 모든 분할 위치 탐색" (배경 #243660)
  · "Information Gain 계산" (배경 #2D4A7A, 레이블 #00C853)
  · "가장 큰 IG의 분할 선택" (배경 #243660)
  화살표: #FFB300
- 중앙 수식 박스 (배경 #1E3566, 테두리 #00C853):
  "IG = 불순도(부모) − [n_L/n × 불순도(왼쪽) + n_R/n × 불순도(오른쪽)]" (18pt, #00C853, 고정폭)
- 중앙 하단: 미니 시각 예시 (2개 분할 후보 비교)
  · 후보 A: 분할 후 두 그룹 거의 동질 → "IG 높음" (#00C853)
  · 후보 B: 분할 후 두 그룹 여전히 섞임 → "IG 낮음" (#FF6B6B)
- 하단 바: "나눈 뒤 더 순수해질수록 좋은 분할 — Information Gain이 클수록 선택된다"

[슬라이드 5 — 트리는 무엇을 기준으로 자를까 — 불순도 감소]
레이아웃: 좌우 2분할 비교 + 하단 계산 예시
- 제목: "트리는 무엇을 기준으로 자를까 — 불순도 감소"
- 좌측 (배경 #243660): "Gini Impurity"(#00C853, 22pt, Bold)
  · 수식: "1 − Σpᵢ²" (24pt, #00C853, 고정폭, 배경 #1E3566)
  · "무작위 추출 시 잘못 분류될 확률"
  · 범위: "0(순수) ~ 0.5(최대 불순, 이진)" (16pt)
  · 태그: "log 없음 → 계산 빠름"(#9DA8B7, 15pt)
- 우측 (배경 #243660): "Entropy"(#FFB300, 22pt, Bold)
  · 수식: "−Σpᵢ log₂(pᵢ)" (24pt, #FFB300, 고정폭, 배경 #1E3566)
  · "정보이론적 불확실성 측도"
  · 범위: "0(순수) ~ 1(최대 불순, 이진)" (16pt)
  · 태그: "분할에 더 예민"(#9DA8B7, 15pt)
- 하단 계산 예시 박스 (배경 #1E3566, 테두리 #9DA8B7):
  "예시: A 7개, B 3개 → Gini = 1−(0.49+0.09) = 0.42  |  Entropy ≈ 0.88" (17pt, #E8EAF0, 고정폭)
  "회귀 트리에서는 Gini/Entropy 대신 MSE를 불순도로 사용" (16pt, #9DA8B7)
- 하단 바: "핵심은 Gini와 Entropy의 차이보다 분할 후 얼마나 더 순수해졌는가이다"

[슬라이드 6 — 트리가 깊어질수록: 과적합]
레이아웃: 좌우 2개 차트 나란히 (핵심 시각 슬라이드)
- 제목: "트리가 깊어질수록 — 높은 분산"
- 좌측 차트 (네이티브 산점도):
  제목: "얕은 트리 (max_depth=2) — 일반화 O" (18pt, #00C853)
  · 데이터 점들 + 단순한 이진 분할 경계선 2~3개
  · 새 데이터 점(빨간 별) → 경계가 적절히 구분
  · 하단: "훈련 오차: 중간 / 테스트 오차: 낮음" (14pt, #9DA8B7)
- 우측 차트 (네이티브 산점도):
  제목: "깊은 트리 (max_depth=∞) — 과적합" (18pt, #FF6B6B)
  · 같은 점들 + 각 점 주위를 꼭 맞게 둘러싼 복잡한 경계
  · 같은 위치 새 데이터 점(빨간 별) → 잘못 구분됨
  · 하단: "훈련 오차: 0 / 테스트 오차: 매우 높음" (14pt, #FF6B6B)
- 두 차트 사이: "분산 ↑↑↑" (18pt, #FF6B6B, 세로)
- 우하단 핵심 박스 (배경 #3A1F1F, 테두리 #FF6B6B):
  "데이터가 조금 달라지면 트리 구조가 크게 달라진다 = 높은 분산" (16pt)
- 하단 바: "단일 트리는 과적합한다 — 이것이 앙상블이 필요한 이유다"

[슬라이드 7 — 가지치기 + 한계]
레이아웃: 상하 2분할 + 결론 강조
- 제목: "가지치기 (Pruning) — 그래도 한계가 있다"
- 상단 절반 (배경 #243660): "사전 가지치기"(#FFB300, 22pt, Bold)
  · 3개 파라미터 태그 (배경 #1E3566): "max_depth" / "min_samples_split" / "min_samples_leaf"
  · 강점: "과적합 사전 방지" (#00C853) | 약점: "좋은 분할도 놓칠 수 있음" (#FF6B6B)
- 하단 절반 (배경 #243660): "사후 가지치기"(#00C853, 22pt, Bold)
  · "완전히 키운 뒤 → 성능 기여 없는 가지 제거"
  · "비용-복잡도 가지치기 (Cost-Complexity Pruning)" (17pt, #9DA8B7)
- 중앙 결론 박스 (배경 #00C853, 텍스트 #1A2744, Bold, 20pt):
  "가지치기는 단일 트리를 덜 위험하게 만들 뿐이다 → 높은 분산 자체를 줄이려면 앙상블이 필요하다"
- 하단 바: "가지치기는 보완책이다 — 높은 분산을 줄이는 본격 해법은 앙상블이다"

──── STEP 2-C: 앙상블 & 배깅 (슬라이드 8~13) ────

[슬라이드 8 — 왜 여러 트리를 합치면 더 좋아지는가]
레이아웃: 중앙 집중형 + 핵심 조건 강조
- 제목: "왜 여러 트리를 합치면 더 좋아지는가 — 핵심은 다양성"
- 중앙 대형 강조 (배경 #243660, 라운드):
  "여러 약한 모델을 결합해서 강한 모델을 만든다" (24pt, Bold, #00C853)
- 그 아래: 직관 설명 박스 (배경 #1E3566)
  "Wisdom of Crowds: 개별 전문가보다 군중의 평균이 더 정확하다" (18pt, #E8EAF0)
  "— 단, 각자 독립적으로 판단할 때만" (17pt, #9DA8B7)
- 우측 경고 박스 (배경 #3A1F1F, 테두리 #FF6B6B):
  "핵심 조건"
  "각 모델이 서로 다른 방향으로 틀려야 한다"
  "같은 방향 오류 × 100 = 더 크게 틀림" (17pt)
- 하단 바: "다양성을 어떻게 만드느냐 — 그것이 배깅과 부스팅의 설계 방향이다"

[슬라이드 9 — 배깅의 수학: σ²/n]
레이아웃: 중앙 수식 + 상관 효과 설명
- 제목: "배깅이 분산을 줄이는 이유 — σ²/n"
- 중앙 상단 수식 박스 (배경 #243660):
  "독립인 경우: Var(X̄) = σ²/n" (32pt, #00C853, 고정폭)
  아래: "n개 트리의 평균 분산 = 단일 트리 분산 / n" (18pt, #9DA8B7)
- 중앙 하단 현실 박스 (배경 #1E3566, 테두리 #FFB300):
  "현실: 트리들은 상관(ρ)이 있다"
  "Var(평균) = ρσ² + (1−ρ)σ²/n" (20pt, #FFB300, 고정폭)
  아래: "ρ가 클수록 첫 항이 지배 → 배깅 효과↓" (17pt)
  아래: "ρ를 낮추는 것이 핵심 → Random Forest의 아이디어" (17pt, #00C853)
- 화살표: ρ 감소 → 분산 감소 (#00C853)
- 하단 바: "트리가 독립적일수록 배깅 효과가 크다 — 상관을 낮추는 것이 핵심"

[슬라이드 10 — Bootstrap 복원 추출]

[슬라이드 16 — Gradient Boosting: 잔차와 경사 하강]
레이아웃: 잔차 누적 다이어그램 + 수학적 연결
- 제목: "Gradient Boosting — 잔차는 손실의 기울기다"
- 상단 한 줄 맥락 박스 (배경 #1E3566):
  "AdaBoost는 지수 손실 고정 → 이상치에 취약 | GBM은 손실 함수를 자유롭게 교체 가능하게 설계" (16pt, #9DA8B7)
- 중앙 좌측: 잔차 학습 흐름 (세로, 화살표)
  ① "F₀: 초기 예측" (배경 #2D4A7A)
  ↓ "잔차 r₁ = y − F₀(x)" (배경 #3A1F1F, #FF6B6B)
  ② "h₁: r₁을 학습" → "F₁ = F₀ + η·h₁" (배경 #2D4A7A)
  ↓ "잔차 r₂ = y − F₁(x) (더 작아짐)" (배경 #3A1F1F, #FF6B6B, 더 작게)
  ③ "h₂: r₂를 학습 …" (배경 #2D4A7A)
  → "예측 = F₀ + η·h₁ + η·h₂ + …" (배경 #00C853, 텍스트 #1A2744, Bold, 20pt)
- 중앙 우측: 수학 연결 박스 (배경 #1E3566, 테두리 #FFB300)
  "잔차 = −∂L/∂F (MSE의 경우)"
  "잔차 학습 = 손실의 음의 기울기 방향으로 업데이트"
  "= 경사 하강법" (18pt, #FFB300, 고정폭)
  아래: "손실 함수 교체 가능:"
  "회귀 → MSE / 분류 → Log Loss / 이상치 강건 → MAE/Huber" (16pt, #9DA8B7)
- 하단 박스: "η (학습률): 작으면 일반화↑ 느림 / 크면 빠르지만 과적합 위험" (17pt, #FFB300)
- 하단 바: "1차시의 손실 최소화가 — 이 구조 안에 직접 들어와 있다"

[슬라이드 17 — XGBoost — GBM을 더 빠르고 더 안정적으로 만든 버전]
레이아웃: 3열 개선점 카드 + 목적 함수
- 제목: "XGBoost — GBM을 더 빠르고 더 안정적으로 만든 버전"
- 중앙 상단 목적 함수 박스 (배경 #1E3566, 테두리 #00C853):
  "목적 = Σ Loss(y, ŷ) + Ω(트리 복잡도)" (20pt, #00C853, 고정폭)
  아래: "Ω = γ×(리프 수) + λ×Σ(리프 가중치²)" (18pt, #FFB300, 고정폭)
  "손실 최소화와 과적합 제어를 동시에 최적화" (16pt, #9DA8B7)
- 중앙 하단 3개 카드 (가로 배열):
  · 카드1 (배경 #243660): "2차 근사" (#00C853, 22pt, Bold)
    "1차 미분만이 아니라 2차(Hessian)까지 사용"
    "Newton 방식으로 더 빠른 수렴" (18pt)
  · 카드2 (배경 #243660): "복잡도 제어" (#00C853, 22pt, Bold)
    "트리의 크기와 리프 가중치를 함께 제어"
    "과적합을 줄이며 일반화를 강화" (18pt)
  · 카드3 (배경 #243660): "속도 최적화" (#00C853, 22pt, Bold)
    "특성 정렬 + 병렬 처리"
    "결측값 자동 처리" (18pt)
- 하단 구분선 위: "LightGBM: 레벨 방향 → 리프 방향 성장 | 대용량 데이터에 더 빠름" (16pt, #9DA8B7)
- 하단 바: "GBM의 약점(속도, 과적합)을 수학적으로 보완한 것이 XGBoost다"
