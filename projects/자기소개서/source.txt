## 소재 상세: forecast (팩트 라이브러리)

**제목:** Distributional Overconfidence in FOMC Rate Expectations: A Density Forecast Evaluation of CME FedWatch

**한 줄 요약:** CME FedWatch 금리 확률분포가 구조적으로 과신(overconfidence)을 보인다는 것을 밀도예측 평가 지표로 실증한 경제학 연구.

---

### 데이터
- 출처: CME FedWatch (시장 암묵 확률분포), FRED (거시지표), BBG (자산가격)
- 기간: 2025년 5월 ~ 2026년 1월
- 확정 FOMC 회의: 7회 (May 2025 ~ Jan 2026), 8번째(2026-01-28) 포함 시 8회
- 관측치: 지평별 75~795개, 총 1,663개 (horizon × meeting 패널 구조)
- 지평 구분: Immediate(0-14일), VeryShort(15-60일), Short(61-180일), Long(181일+)

---

### 핵심 발견 (숫자로 말하는 것들)

**과신의 규모:**
- 80% 예측 구간 → 실제 포함률 **13.3%** (회의 직전 Immediate 지평)
- 이론상 80% 구간이 80%를 커버해야 하지만, 실제론 13.3%만 포함 → 6배 이상 과소추정

**VIX 조건부 분석:**
- β = -0.017 (t = -7.77, p < 0.001)
- VIX가 높을수록 FedWatch 불확실성은 더 좁아짐 → 공포 시기에 오히려 더 과신

**뉴스 충격 (News Impact):**
- NFP (비농업고용) abs_ratio = 3.87 → 가장 강한 충격 이벤트
- CPI abs_ratio ≈ 2.5 수준
- 충격 후 평균 해소 시간: 약 3~7일

**정보 해소 경로 (Uncertainty):**
- 평균 58일 전 불확실성의 90% 해소 (Bundick 2022 복제 확인)
- 회의별 이질성: char_time CV = 0.26 → 중간 수준 이질성

**LASSO 예측력:**
- 과신 정도를 거시지표로 예측 시도 → R² ≈ 0
- 해석: 과신은 특정 상황의 산물이 아니라 구조적 편향

**장기 지평 예측 실력:**
- Long horizon skill score = -0.590
- naive baseline(과거 평균)보다 나쁨 → 먼 미래일수록 시장 예측이 오히려 역효과

**Granger 인과:**
- VIX → coverage_shortfall: 유의 (시장 변동성이 과신 정도를 선행)
- 역방향(shortfall → VIX)은 약함

### 방법론 (쓸 수 있는 용어들)

| 지표 | 의미 | 논문 적용 |
|------|------|-----------|
| CRPS | Continuous Ranked Probability Score — 예측분포 전체 평가 | 지평별 비교 |
| PIT | Probability Integral Transform — 예측분포 균일성 검정 | 과신 방향 확인 |
| Coverage Rate | 실제값이 예측구간 내 포함된 비율 | 80% 구간 → 13.3% |
| Log Score | `-log f(r_T)` — 예측 밀도의 적합도 | KDE 근사 |
| Interval Score | 구간 길이 + 벌점 결합 지표 | 80%/90% 구간 |
| LASSO | L1 정규화 회귀 — 과신 예측 변수 선택 | Adaptive LASSO (Zou 2006) |
| Wild Bootstrap | 이분산·비정규 잔차 강건 검정 | 계수 신뢰구간 |
| Block Bootstrap | 시계열 자기상관 보정 | t-통계량 검정 |
| HAC | Heteroskedasticity-Autocorrelation Consistent SE | 클러스터 수 <15 시 대체 |
| Granger 인과 | 변수 간 선행 관계 검정 | VIX → coverage_shortfall |

### 프로젝트 성격
- **Solo end-to-end**: 가설 수립 → 데이터 수집 → 분석 → 논문 초안까지 혼자
- **도구**: Python (pandas, statsmodels, sklearn), 파이프라인 자동화
- **상태**: 진행 중 (분석 완료, 논문 초안 작성 중)
- **포지셔닝 핵심**: "시장의 자신감을 의심하고 검증한 경제학 연구"
