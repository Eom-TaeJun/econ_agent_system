# NH투자증권 Trading 자소서 소스·키워드·플로우 계획 (2026 Q1)

기준일: 2026.03.14

목적:
- 자소서 전체 문장을 쓰기 전에
  `무슨 소재를 어디에 배치할지`
  `어떤 키워드를 반복할지`
  `어떤 사람으로 읽히게 할지`
  먼저 고정한다.

---

## 1. 최종 사람상

이번 자소서에서 보여야 할 사람은 아래다.

**금리와 채권 시장을 확률과 시나리오로 해석하고, 시장의 과신과 리스크를 검증해 NH Trading desk가 읽을 수 있는 대응 메모로 구조화하는 지원자**

이 문장에 없는 요소는 전면에 두지 않는다.

예:
- 범용 AI 개발자
- 데이터 분석가
- 자동매매형 지원자
- 크립토 중심 지원자
- 수익률 자랑형 지원자

---

## 2. 메인 소스와 역할

### 소스 1. `forecast`

역할:
- 자소서의 `핵심 실력`을 증명
- 금리/채권/FICC 사고방식을 보여주는 메인 경험

보여줄 것:
- 금리 기대를 점 전망이 아니라 분포로 봤음
- 시장 과신을 검증했음
- 정책, 변동성, 채권시장 신호를 연결해 해석했음
- 결과가 직관과 달라도 검증과 해석을 밀어붙였음

키 팩트:
- `80% -> 13.3%`
- `VIX 조건부 과신`
- `MOVE 선행`
- `예측 가능한 단순 편향이 아님`

### 소스 2. `eimas_nh`

역할:
- `forecast`의 문제의식을 NH 실무 언어로 번역한 증거
- 분석이 아니라 `desk memo`로 확장했다는 점을 보여줌

보여줄 것:
- thesis / base case / risk case / handoff 구조
- 정책, 커브, 유동성, 리스크를 함께 보게 설계
- 전망을 대응 전략으로 바꾸는 훈련

### 소스 3. 전공 / 자격증 / 코딩

역할:
- 메인 스토리를 보조하는 `기본기` 신호
- 따로 문단을 주지 않음

보여줄 것:
- 경제학 전공
- 통계/데이터 분석 기본기
- 필요한 데이터를 직접 다루고 검증할 수 있음

### 소스 4. POSCO / Parrot

역할:
- 선택적 보조 소재
- 복잡한 내용을 배우고 설명할 수 있는 사람이라는 보완

원칙:
- 필요하면 2~3문장만
- main story를 밀어내지 않음

## 7. 흐름 연결 공식

자소서 전체 흐름은 아래 한 줄로 정리된다.

`금리 기대의 과신을 검증했다 -> 그 판단을 대응 메모로 번역했다 -> NH는 이런 판단을 실제 전략과 상품 언어로 연결하는 회사다 -> 그래서 NH Trading에서 가장 잘 쓰일 준비를 해왔다`

이 공식에서 벗어나지 않으면
자소서가 흔들리지 않는다.

---

## 8. 문장 톤 원칙

- `연구를 했다`보다 `검증했다`, `해석했다`, `구조화했다`
- `AI를 만들었다`보다 `메모로 번역했다`
- `예측했다`보다 `과신과 리스크를 점검했다`
- `열심히 했다`보다 `어떤 판단 기준을 얻었는지`

즉 행동보다 `판단 언어`가 보여야 한다.
