## 1. 공통 작성 원칙

2026년 2월 이후 공식 채용/가이드 문구를 보면,
회사들이 직접 `자소서 잘 쓰는 법`을 길게 주기보다는 아래 항목을 반복한다.

1. 직무 적합성
2. 문제 해결
3. 구체적인 경험과 성취
4. 가치관/태도 일관성
5. 검증 가능한 설명
6. 회사 언어로 번역된 결과

따라서 자기소개서 규칙은 다음이 맞다.

- 프로젝트는 `역량 축적 -> 문제 해결 -> 결과 -> 직무 번역` 순으로 쓴다.
- AI/데이터 경험은 `도구`보다 `성과와 의사결정 개선`으로 쓴다.
- 숫자와 사례는 면접에서 다시 설명 가능한 수준까지만 쓴다.
- 각 회사가 직접 쓰는 단어를 우선 사용한다.

## 2. 삼성생명 — 디지털 서비스 기획/운영

### 회사가 직접 말한 것

- 직무 소개:
  `디지털채널의 전략을 수립하고 운영하며 비즈니스 수행에 필요한 데이터 인사이트를 제공하고, 데이터 분석을 통해 실질적인 성과를 창출`
- 지원 가이드:
  `직무적합성평가`는 `직무에 대한 역량을 쌓기 위해 노력하고 성취한 내용`을 평가
- 지원 가이드:
  `전공과목 이수 내역`, `직무관련 활동 경험`, `에세이`를 바탕으로 평가하며 `그 외 직무와 무관한 스펙은 일체 반영되지 않습니다`
- 회사 2030 방향:
  `보험을 넘어, 고객의 미래를 지키는 인생금융파트너`
- 중장기 전략:
  `디지털 Value Chain 전반의 Transformation 완성`
  `헬스케어 및 플랫폼 사업기반 구축`
  `미래지향적 멀티채널 구조 혁신`

## 6. 삼성증권 — AI 서비스 기획/운영

### 회사가 직접 말한 것 (JD)

- `데이터 기반 마케팅`
- `디지털기술 기반 금융서비스 기획/운영`
- `데이터 분석/활용 및 AI서비스 구축`
- `고객 니즈 분석 → 경영 현안·비즈니스 인사이트 도출`
- `전사 데이터 분석 지원, 실시간 대시보드 구축·운영`
- `AI 서비스 기획 + 알고리즘 설계·최적화`

자소서 항목 (2026 상반기):
1. 지원동기 + 꿈 (700자)
2. 성장과정 + 영향을 끼친 사건/인물 (1500자)
3. 사회이슈 + 견해 (1000자)
4. 새로운 방식으로 접근한 성공 경험 (1000자)

### 이 회사가 원하는 사람상

- 금융 AI 서비스를 기획하고 알고리즘 수준까지 이해하는 사람
- 분석을 고객 서비스로 연결하는 사람
- 기술 자랑이 아니라 비즈니스 인사이트로 말하는 사람

### 자기소개서에서 써야 할 표현

- `종합 투자 플랫폼`
- `데이터 기반 고객가치`
- `비즈니스 인사이트`
- `AI서비스 구축`
- `알고리즘 설계·최적화`

### 피해야 할 표현

- 자동매매, 수익률 예측 중심 설명
- 모델명·프레임워크 기술 자랑
- "AI가 모든 걸 해결한다" 식 낙관론

### EIMAS / forecast 번역법

- EIMAS:
  `금융 시장 분석을 위한 다중 AI 에이전트 시스템을 직접 설계·구축·운영한 경험`
- forecast:
