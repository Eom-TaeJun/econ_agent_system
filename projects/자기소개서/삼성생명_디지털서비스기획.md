## Q1. 지원동기 + 꿈 (700자)

**구조:** 보험의 본질(리스크) → forecast 경험 연결 → 삼성생명에서 하고 싶은 것

**도입:** 보험은 리스크의 가격을 매기는 산업. "리스크를 정확히 측정하고 있는가"라는 질문에 데이터로 답해본 경험이 이 직무로 이끌었다.

**경험 연결:** 금융 시장 확률 예측 데이터 분석 → 시장이 방향은 맞추지만 확신을 과대평가 → "80% 확신" 구간에 실제 13%만 포함 → 고객이 인지하는 리스크와 실제 리스크의 괴리를 데이터로 보여주는 것이 금융 서비스의 출발점이라는 확신

**왜 삼성생명:** 디지털채널을 통해 고객 접점 확대 중. 데이터 인사이트를 디지털 서비스에 녹여 고객이 자신의 리스크를 직관적으로 이해하고 스스로 보장 설계할 수 있는 경험을 만들고 싶다.

**꿈:** 데이터 분석이 보고서에 머무르지 않고, 고객 화면 위에서 행동을 바꾸는 서비스로 전환되는 과정에 기여

**Codex 인사이트 활용:**
- "시장 데이터가 표현하지 못하는 불확실성까지 검증" → 보험(리스크 상품)과 직결
- 실무 시사점(VaR 과소평가, 시나리오 분석) → 삼성생명 리스크관리 착지

**금지어:** CRPS, PIT, Berkowitz 등 메트릭 이름 / "논문" → "연구 프로젝트"로

## Q2. 성장과정 (1500자)

**구조:** 과학고(수리적 사고) → 경제학(현상 해석) → 데이터/AI(도구) → 전환점

- 서사: 이과적 사고 → "숫자 뒤의 의사결정 구조"에 관심 → 데이터로 둘을 연결
- 1500자로 가장 길기 때문에 서사의 깊이를 보여줘야 함

**영향을 준 인물 3명 (택1 또는 조합):**

| 인물 | 키워드 | 연결 가능한 서사 |
|------|--------|----------------|
| 오타니 쇼헤이 | 불가능에 대한 도전, 자기관리→결과, 야구의 개념을 바꿈, 입문자에게 영향 | "이도류처럼, 경제학+데이터/AI 두 영역을 함께 추구" |
| A교수님 | 자기 분야의 경지+AI 활용, 금융 분석의 불가능에 도전, 자신감 있는 전문성, 예측이 실제로 맞음, 롤모델 | "나도 저렇게 하고 싶다 → forecast 프로젝트의 직접적 동기" |
| 일론 머스크 | 불가능 도전, 살아있을 때 결과 확인하려는 집념, 최정상에서도 더 뛰어다님 | "현재에 안주하지 않는 자세" |

**결정:** A교수님을 메인으로 사용

**Q2 구조 (1500자):**
```
[1막] 출발점 (300자)
  과학고에서 수리적 사고 훈련 → 경제학과 진학
  "현상을 설명하고 싶은데 이론만으로는 부족" → 데이터/AI를 도구로

[2막] 전환점 — A교수님 (500자, 핵심)
  2025년 9월 수업에서 처음 만남
  자기 분야의 경지 + AI를 활용해 금융 분석의 불가능에 도전
  자신감 있게 과정과 결과를 이야기하는 전문성과 노력
  실제로 그 예측이 맞았다는 것을 확인 → "나도 저렇게 하고 싶다"

[3막] 실행 — forecast + EIMAS (500자)
  forecast: 금리 예측 확률분포 직접 분석 → "80%→13%" 구조적 과신 발견 (연구적 깊이)
  여기서 멈추지 않고 EIMAS로 확장:
    - 다중 AI 모델 토론, 레짐 탐지, 포트폴리오 최적화
    - 실시간 시장 분석·의사결정 지원 시스템 설계·운영
  최신 AI 기술 학습하며 지금도 고도화 중 (분석→시스템으로 만드는 사람)

[마무리] (200자)
  분석을 서비스로 전환하는 경험 → 삼성생명 디지털 서비스 기획으로 연결
```

**포인트:** forecast만 쓰면 "연구자", EIMAS까지 넣으면 "분석을 시스템으로 만드는 사람" → 디지털 서비스 기획에 부합

## Q3. 사회이슈 (1000자)

**추천 방향:**

### A안 (추천): AI 시대 금융 소비자의 리스크 인지 괴리
- "시장도 틀리는데, 개인은 더 틀린다" → 디지털 금융 리터러시 필요성
- forecast 논문과 직결되어 자연스러운 연결

### B안: 보험/금융의 디지털 전환과 데이터 활용
- 데이터 기반 개인화 vs 개인정보 보호 균형
- 직무(디지털 서비스 기획)와 직결

**확정: 에이전트 AI 시대**

**관통 논리:** "AI도 과신한다" (EIMAS 경험) + "시장도 과신한다" (forecast) + "R²≈0도 성과" → 따라서 중요한 건 AI를 쓰는 게 아니라 AI의 판단을 검증하고 신뢰할 수 있게 전달하는 것

**구조 (1000자):**
```
[도입] 에이전트 AI가 스스로 분석·판단·실행하는 시대 (200자)
  단순 도구가 아닌, 의사결정까지 하는 AI로 진화 중

[경험 기반 견해] AI도 확신에 차서 틀린다 (400자)
  다중 AI 에이전트 시스템을 직접 구축한 경험
  AI가 자신감 있게 잘못된 판단을 내리는 순간 목격
  시장 참여자가 80%→13%로 과신하듯, AI도 과신한다
  R²≈0이라는 결과가 "실패"가 아니라 "한계의 발견"인 것처럼
  AI의 출력도 맹신이 아닌 검증의 대상

[착지] 디지털 서비스 기획자의 역할 재정의 (300자)
  에이전트 AI 시대에 기획자는 "AI를 도입하는 사람"이 아니라
  "AI와 고객 사이에서 신뢰를 설계하는 사람"
  AI의 판단을 검증하고, 고객이 이해할 수 있는 형태로 번역하는 것
  → 삼성생명 디지털 서비스에서 이 역할을 하고 싶다
```

**차별화 포인트:** 남들은 "에이전트 AI가 세상을 바꿀 것이다"(예측), 본인은 "만들어보니 AI도 과신한다"(경험)

## Q4. 차별화 강점 (1000자)

**강점 정의:** "분석 → 해석 → 전달, 전 과정을 혼자 완결하는 능력"

**근거 배치:**

| 순서 | 소재 | 증명 |
|------|------|------|
| 근거 1 | forecast 프로젝트 | 데이터 수집→분석→시각화 end-to-end 자기주도 |
| 근거 2 | POSCO 불량률 분석 | 모르는 도메인 빠른 학습 + 듣는 사람 기준 전달 |
| 보조 | Parrot ML 강의 | 1년 만에 배우는 쪽→가르치는 쪽 전환 = 전달력 |

**착지:** "디지털 서비스 기획은 데이터를 분석하는 것에서 끝나지 않고, 고객과 현업이 이해할 수 있는 형태로 바꾸는 일. 저는 그 전 과정을 해본 사람."

**Codex 인사이트 활용:**
- 강점 정의를 "불확실성까지 검증하는 방식으로 문제를 재정의하는 능력"으로 격상 가능
- "모델 성능보다 한계·검증·해석이 중요" → POSCO 경험(듣는 사람 기준 전달)과 일관
- forecast end-to-end 서술 시: "불완전한 데이터를 연구 가능한 구조로 바꿨다"는 표현 활용
