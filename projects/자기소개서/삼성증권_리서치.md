# 삼성증권 리서치 — 자소서 전략

> 마감: 2026.03.17
> 포지셔닝: "금융 데이터를 직접 연구하고 시장의 과신을 실증한 경제학 전공자"
> JD: 양질의 리서치 보고서, 투자 전략, 유망 종목/상품 분석, 글로벌 금융시장 분석, 종합 투자전략 제안

---

## 핵심 포지셔닝

> "CME FedWatch의 80% 구간이 실제론 13.3%만 맞는다는 것을 직접 실증한 경제학 연구자"

**왜 이 포지션인가:**
- 리서치 지원자 100명 중 실제 금융 리서치를 end-to-end 수행한 사람은 거의 없다
- 경쟁자들은 CFA + 인턴 → "준비 중인 사람"
- 나는 forecast → "이미 해본 사람"
- EIMAS → "AI 시대 리서치 방식을 고민한 사람"

**삼성증권 리서치가 원하는 인재:**
- 금융시장 이해 + 시장센싱 + 데이터 분석 역량
- 분석을 설득력 있게 전달하는 능력
- AI 시대에도 도메인 분석 전문성 (AI서비스기획 신설로 더 명확해진 포지션)

## Q1. 지원동기 + 꿈 (700자)

**구조:** 연구 경험 → 갭 발견 → 삼성증권 연결 → 꿈

**도입:** 직접 시장 데이터를 분석하면서 "이 분석이 실제 투자자에게 전달되면 어떨까"라는 질문이 생겼다.

**경험 연결:**
- forecast: CME FedWatch 금리 확률분포를 분석하다 80%→13.3% 발견
- 시장 참여자들이 얼마나 틀린 확신을 갖는지 데이터로 확인
- 이 발견이 개인 투자자에게 전달된다면 의사결정이 달라질 수 있다

**왜 삼성증권 리서치:**
- 개인 투자자까지 닿는 리서치 채널 (유튜브·버추얼 애널리스트 등)
- 단순 수익률 예측이 아닌 시장 구조를 해석하는 리서치를 하는 곳
- 리서치가 투자자의 의사결정에 직접 연결되는 접점

**꿈:** 개인 투자자가 "이 정보를 어떻게 믿어야 하는가"를 판단할 수 있도록 돕는 리서치. 수익률이 아닌 불확실성을 정직하게 전달하는 애널리스트.

**금지어:** 수익률 예측, 자동매매, "돈을 벌고 싶어서"
**삼성증권 언어:** 종합 투자 플랫폼, 데이터 기반 투자정보, 시장센싱, 금융시장 이해

## Q2. 성장과정 (1500자)

**구조:** 과학고(수리) → 경제학(현상 해석) → A교수님(전환점) → forecast → EIMAS

```
[1막] 출발점 (300자)
  과학고에서 수리적 사고 훈련 → 경제학과 진학
  "숫자 뒤의 의사결정 구조"에 관심

[2막] 전환점 — A교수님 (500자, 핵심)
  2025년 9월 수업
  금융 분석의 불가능에 도전하는 모습 목격
  실제 예측이 맞았음을 확인 → "나도 저렇게 하고 싶다"

[3막] 실행 — forecast (500자)
  금리 예측 확률분포 분석 → 시장의 과신 구조 발견
  80%→13.3%: 데이터가 직관을 뒤집는 순간
  혼자 데이터 수집부터 계량 분석, 논문 초안까지
  EIMAS로 확장: 분석을 시스템으로 만드는 시도

[마무리] (200자)
  연구에서 멈추지 않고 실제 투자자에게 연결하고 싶다
  → 삼성증권 리서치
```

## Q3. 사회이슈 (1000자)

**주제: 금융 정보의 과신 — AI 시대에 더 위험해진 문제**

**관통 논리:**
시장도 과신한다(forecast 80%→13%) + AI도 과신한다(EIMAS 경험)
→ 중요한 건 분석 결과가 아니라 "얼마나 믿어야 하는가"를 함께 전달하는 것

**구조 (1000자):**
```
[도입] 금융 정보 홍수 시대 (200자)
  AI가 투자 분석을 자동 생성하는 시대
  개인 투자자는 더 많은 정보를 접하지만, 어디까지 믿어야 하는지 모름

[경험 기반 견해] 시장의 과신, AI의 과신 (400자)
  CME FedWatch 분석: 80% 확신이 실제론 13.3%
  → 가장 유동적이어야 할 순간에 오히려 더 좁아지는 시장
  EIMAS: AI 에이전트도 자신감 있게 틀린 판단을 내림
  → 과신은 인간만의 문제가 아님

[핵심 주장] 리서치의 역할 재정의 (300자)
  "얼마나 맞는가"가 아니라 "얼마나 불확실한가"를 전달하는 것
  확률구간, 시나리오 복수 제시, 전제 조건 명시
  이것이 AI 시대 리서치의 경쟁력

[마무리] (100자)
  신뢰할 수 있는 리서치 = 틀릴 가능성을 함께 알려주는 리서치
```

## Q4. 새로운 방식으로 접근한 경험 (1000자)

**소재: forecast — 점 예측이 아닌 밀도예측 접근**

**구조:**
```
[기존 방식의 한계] (200자)
  금리 예측 = 보통 "몇 %로 오를 것인가" (점 예측)
  하지만 점 예측은 불확실성을 숨긴다

[새로운 접근] (300자)
  확률분포 전체를 평가하는 밀도예측 방법론 적용
  CRPS, PIT, Coverage Rate — 예측의 "폭"을 측정
  기존 금융 예측 연구에서 잘 쓰이지 않던 방법을 직접 적용

[과정과 장벽] (200자)
  관련 논문·코드 없음 → 직접 파이프라인 구축
  PIT 검정 해석, Bootstrap 방법 선택 등 반복 수정

[결과] (200자)
  핵심 발견: 시장은 구조적으로 과신한다 (R²≈0 — 예측 불가능한 편향)
  LASSO로 예측하려 했으나 실패 → 실패가 곧 발견

[배운 것] (100자)
  새로운 방식의 핵심은 도구가 아니라 "무엇을 측정할 것인가"의 질문
```

**주의:** R²≈0을 "실패"가 아니라 "구조적 발견"으로 서술할 것

- `데이터 기반 투자정보`
- `투자전략 제안`

피해야 할 표현:
- 수익률 예측, 자동매매
- AI가 모든 걸 해결 (낙관론)
- 모델명/프레임워크 자랑 (LangChain, GPT-4 등)
