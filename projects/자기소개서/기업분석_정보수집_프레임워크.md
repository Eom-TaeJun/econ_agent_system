# 기업 직무 분석 — 정보수집 프레임워크

> 목적: 공채 지원 전, 기업이 보내는 시그널을 체계적으로 수집하여
> "이 회사의 이 직무를 위해 준비한 사람"처럼 보이는 자소서 전략 수립
>
> 이론 배경: 정보경제학의 스크리닝·시그널링
> — 기업은 JD·우대사항·서비스 출시·인사를 통해 원하는 인재 시그널을 보낸다.
> — 지원자의 역할: 그 시그널을 해독하고 내 경험을 그 언어로 번역하는 것.

---

## Phase 0: 수집 전 체크리스트

```
[ ] 지원 회사·직무 가설 1~3개 설정
[ ] 내 소재 목록 확보 (source.txt)
[ ] 마감일 확인
[ ] 삼성 등 대기업: 직무적합성 평가 방식 확인 (전공 이수 체크 여부)
```

---

## Phase 1: 직무 구조 분석 (JD 레이어)

### 1-1. 연도별 JD 변화 추적

**수집 방법:**
```
검색: "[회사명] [연도] 공채 직무 우대사항"
검색: "[회사명] 직무 상세 정보 PDF [연도]"
사이트: jasoseol.com, linkareer.com, catch.co.kr, samsungcareers.com
```

**수집 항목:**
- 직무 목록 변화 (신설·폐지·통합·분리)
- 자격요건 변화
- 우대사항 변화 (키워드 추가·삭제)
- 직무 설명 문구 변화

**해석 방법:**
```
신설 직무 → 회사가 새로 키우려는 역량
폐지·통합 직무 → 중요도 하락 또는 외주화
우대사항 추가 키워드 → 현재 가장 필요한 역량
우대사항 삭제 키워드 → 이미 내재화됐거나 방향 변경
```

**삼성증권 사례:**
- 2026년 AI서비스기획 신설 → CS/AI 전공 + 딥러닝 명시
- 디지털서비스기획에서 AI 내용 제거 → 기획/UX 중심으로 재정의
- 결론: "AI 개발자"와 "도메인 분석가" 채널 분리

---

### 1-2. 직무 설명 언어 수집

**왜 중요한가:**
자소서는 회사의 언어로 써야 한다. JD에 있는 단어를 자소서에서 그대로 쓰면
인사담당자가 "이 사람이 우리 직무를 이해하고 있다"고 느낀다.

**수집 항목:**
- JD에서 반복되는 동사 (분석, 기획, 운영, 제안, 설계)
- JD에서 반복되는 명사 (고객가치, 데이터, 플랫폼, 인사이트)
- 공식 표현 (회사 고유 언어)

**피해야 할 표현:**
- 다른 계열사·경쟁사 언어 (삼성증권 ↔ 삼성생명 혼동 등)
- 직무와 맞지 않는 기술 자랑

## Phase 2: 회사 방향성 분석 (경영 레이어)

### 2-1. CEO 시그널 수집

**수집 방법:**
```
검색: "[회사명] CEO 신년사 [연도]"
검색: "[회사명] 대표이사 인터뷰 [연도]"
검색: "[회사명] [대표이름] 전략 비전"
사이트: 회사 공식 홈페이지 CEO 인사말, 한국금융신문, 헤럴드경제, 아시아에이
```

**수집 항목:**
- 신년사 키워드 (3~5개)
- 강조하는 가치 (고객, 혁신, 신뢰 등)
- 올해의 전략 우선순위
- 직전 연도 성과와 다음 목표

**해석 방법:**
```
CEO가 반복하는 단어 = 올해 인재상의 핵심
CEO가 강조하는 신사업 = 그 분야 역량 보유자 선호
CEO가 언급하는 약점 = 그 약점을 채울 인재 필요
```

---

### 2-2. 서비스·사업 출시 추적

**수집 방법:**
```
검색: "[회사명] 서비스 출시 [연도]"
검색: "[회사명] 신사업 [연도]"
검색: "[회사명] 출시 발표 [연도]"
사이트: 회사 공식 보도자료, 아시아에이, 뉴스1, 파이낸셜뉴스
```

**수집 항목:**
- 최근 1~2년 신규 서비스명
- 서비스 출시 배경·목표
- 가입자 수·성장 지표
- 기술 파트너십

**해석 방법:**
```
신규 서비스 = 그 서비스를 운영·발전시킬 인재 필요
빠른 성장 서비스 = 증설 채용 가능성
기술 파트너십 = 그 기술 역량 내재화 의도
```

**삼성증권 사례:**
- 로보굴링 가입자 14.6만명 → 알고리즘·운용 역량 지속 필요
- 버추얼 애널리스트 (국내 최초) → 리서치 콘텐츠 AI화 방향

---

### 2-3. 임원 인사 분석

**수집 방법:**
```
검색: "[회사명] 임원 인사 [연도]"
검색: "[회사명] 조직개편 [연도]"
```

**해석 방법:**
```
신설 부서·팀 → 해당 분야 채용 증가 예상
승진자 출신 부서 → 회사가 중시하는 역량 라인
외부 영입 임원 전공 → 그 분야 역량 확보 의도
```

## Phase 3: 경쟁자 지도 파악 (상대우위 레이어)

### 3-1. 합격자 스펙 수집

**수집 방법:**
```
검색: "[회사명] [직무] 합격 자소서"
검색: "[회사명] [직무] 합격자 스펙"
사이트: linkareer.com/cover-letter, jasoseol.com, comento.kr
```

**수집 항목:**
- 합격자 평균 전공·학벌
- 보유 자격증 (CFA, FRM, SQLD 등)
- 주요 경험 (인턴, 대외활동, 프로젝트)
- 어필한 역량 키워드

### 3-2. 지원자 수 파악

**수집 방법:**
```
사이트: jasoseol.com → 직무별 자소서 작성자 수
```

**해석:**
```
지원자 수 많음 → 서류 차별화 어려움, 키워드 필터링 가능성 높음
지원자 수 적음 → 특수 스펙 요구 or 틈새 직무
```

### 3-3. 상대우위 매트릭스 작성

```
| 항목 | 경쟁자 평균 | 나 | 판단 |
|------|------------|-----|------|
| 자격증 | CFA L1 | 없음 | ❌ |
| 인턴 | 금융 인턴 | 없음 | ❌ |
| 실증 연구 | 없음 | forecast | ✅ |
| ...  |            |     |      |
```

**핵심 원칙:**
- 절대우위가 아닌 **상대우위**를 찾는다
- 경쟁자들이 가진 것 = 기본값 (차별화 안 됨)
- 경쟁자들이 없는 것 중 내가 가진 것 = 실질 차별화 포인트

## Phase 4: 교차 분석 (연결 레이어)

### 4-1. 3축 교차표 작성

```
회사 방향  ×  내 소재  =  자소서 연결 표현
────────────────────────────────────────
[회사 방향 A]  ↔  [내 소재 X]  →  "..."
[회사 방향 B]  ↔  [내 소재 Y]  →  "..."
```

### 4-2. 포지셔닝 문장 도출

형식:
```
"[내가 한 것]을 통해 [회사가 원하는 것]을 할 수 있는 [직무 언어로 표현한 인재]"
```

예시 (삼성증권 리서치):
```
"글로벌 금리 시장의 과신을 데이터로 실증하고,
개인 투자자가 불확실성을 이해할 수 있는 리서치를 만들고 싶은 경제학 전공자"
```

## Phase 5: 자소서 작성 원칙

### 5-1. 인사담당자 관점 3원칙

1. **첫 문장이 멈추게 해야 한다**
   - ❌ 추상적 주장: "저는 데이터 분석을 했습니다"
   - ✅ 구체적 숫자: "80% 예측구간이 실제로는 13.3%만 맞습니다"

2. **회사의 언어로 써야 한다**
   - JD·CEO 신년사에서 수집한 단어를 그대로 활용
   - 틀린 언어 = 준비 안 된 사람

3. **준비된 증거를 보여야 한다**
   - 경험의 결과 (숫자, 수상, 출판) > 경험의 과정
   - "했다" < "발견했다" < "실증했다"

### 5-2. 소재 배분 원칙

- 한 문항에 소재 하나 집중 (두 개 넣으면 둘 다 약해짐)
- Q간 소재 중복 금지 (같은 프로젝트 = 각기 다른 측면으로)
  - Q1: 결과·동기
  - Q2: 서사·과정
  - Q3: 의미·견해
  - Q4: 방법·설계
