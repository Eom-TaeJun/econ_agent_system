## 4. 직무 적합성 분석

### 내 보유 소재 (핵심 2개)

**forecast:**
- 내용: CME FedWatch 금리 확률분포 밀도예측 평가 연구
- 방법: CRPS, PIT, Coverage Rate, LASSO, Granger 인과, Block Bootstrap
- 핵심 발견: 80% 예측구간 → 실제 포함률 13.3% (Immediate horizon)
- 성격: 혼자 end-to-end (데이터 수집 → 분석 → 논문 초안)
- 상태: 분석 완료, 논문 초안 작성 중

**EIMAS:**
- 내용: 다중 AI 에이전트 금융 시장분석 시스템 (분석가·반론자·검증자 역할 분리)
- 기술: LLM API 기반 (딥러닝 프레임워크 직접 구현 아님)
- 성과: 설계·운영 중 (현재 진행형)
- 핵심 경험: AI도 과신한다 — 검증 구조 설계가 핵심

## 6. 최종 직무 선택: 리서치

**선택 근거:**
1. forecast = 리서치 직무 그 자체 (금융 데이터 분석 → 인사이트 도출)
2. 경제학 전공 = 리서치의 본진
3. EIMAS = "AI 시대 리서치 방식"에 대한 차별화 레이어

**보완 필요:**
- CFA 부재 → 계량 방법론의 depth와 숫자로 대체
- 섹터 전문성 없음 → 거시/금리 영역으로 자연스럽게 포지셔닝

## 9. 자소서 작성 원칙

### 인사담당자 관점 3원칙
1. **첫 문장이 멈추게 해야 한다**
   - ❌ "저는 금융 데이터를 분석했습니다"
   - ✅ "80% 예측구간이 실제로는 13.3%만 맞는다는 것을 실증했습니다"

2. **회사 언어를 써야 한다**
   - 쓸 것: 글로벌 금융시장, 투자정보, 시장센싱, 데이터 기반, 종합 투자 플랫폼
   - 피할 것: 수익률 예측, 자동매매, 모델명 자랑, AI 낙관론

3. **준비된 사람의 증거를 보여야 한다**
   - forecast = 리서치 직무를 이미 해봤다는 직접 증거
   - EIMAS = AI 시대 리서치 대응 경험

### 각 문항별 핵심 전략

**Q1 (700자):**
- 구조: 연구 발견 → 갭 인식 → 삼성증권 연결 → 꿈
- 핵심: forecast 발견이 실제 투자자에게 연결되지 않는다는 아쉬움 → 리서치 직무로 연결
- 꿈: "수익률이 아닌 불확실성을 정직하게 전달하는 애널리스트"

**Q2 (1500자):**
- 구조: [1막] 배경 → [2막] 전환점(A교수님) → [3막] 실행(forecast+EIMAS) → [마무리]
- 주의: A교수님은 구체적으로 서술 (소속, 수업명 필요)
- 과학고는 짧게 (구체 에피소드 없으면 한 줄 배경으로)

**Q3 (1000자):**
- 주제: "AI 투자정보 시대의 과신 — 신뢰 설계가 리서치의 역할"
- 근거 1: 시장도 과신한다 (80%→13.3%)
- 근거 2: AI도 과신한다 (EIMAS 경험)
- 결론: 리서치의 역할 = 불확실성을 함께 전달하는 신뢰 설계

**Q4 (1000자):**
- 소재: EIMAS — 단일 AI에서 다중 에이전트 검증 구조로
- 연결: AI 판단 검증 경험 → 리서치도 같은 원리
- 주의: 기술 자랑이 아닌 "검증 구조 설계" 관점으로
