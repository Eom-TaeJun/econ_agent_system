정보능력

=== 1. 컴퓨터 기초 ===

[하드웨어 5요소]
- 입력 (키보드·마우스)
- 출력 (모니터·프린터)
- 제어 (CU)
- 연산 (ALU)
- 기억 (주기억·보조기억)

[기억장치 계층]
- 레지스터 → 캐시 → 주기억(RAM) → 보조기억(SSD·HDD)
- 위로 갈수록 빠르고 비싸고 작음

[OS 역할]
- 자원 관리, 프로세스 스케줄링
- 예: Windows, macOS, Linux

=== 2. 엑셀 핵심 함수 ===

[논리·조건]
- IF(조건, 참값, 거짓값)
- IFS(조건1, 값1, 조건2, 값2, ...) — 다중 조건
- AND / OR / NOT

[조회·참조]
- VLOOKUP(찾을값, 범위, 열번호, 일치유형)
  * 범위 첫 열에서 검색
  * 일치유형: FALSE=정확, TRUE=근사
- HLOOKUP: 행 기준
- INDEX(범위, 행, 열) + MATCH(값, 범위, 일치유형) 조합
- XLOOKUP: 신버전 (VLOOKUP 상위호환)

[집계]
- SUM / AVERAGE / COUNT
- SUMIF(범위, 조건, 합계범위)
- COUNTIF(범위, 조건)
- SUMIFS / COUNTIFS — 다중조건

[문자열]
- LEFT(문자, 개수) / RIGHT / MID
- LEN: 문자수
- CONCATENATE: 합치기 (or &)
- TRIM: 공백 제거

[날짜]
- TODAY() / NOW()
- YEAR / MONTH / DAY
- DATEDIF(시작, 끝, "Y"/"M"/"D") — 기간 계산

[오류 처리]
- IFERROR(식, 오류시값)
- 오류 유형: #DIV/0!, #N/A, #VALUE!, #REF!

=== 3. 엑셀 기능 ===

[정렬·필터]
- 정렬: 데이터 → 정렬 (오름·내림)
- 자동필터: 조건 맞는 행만 표시
- 고급필터: 복잡한 조건 조합

[피벗테이블]
- 행·열·값·필터 영역
- 대량 데이터 집계·분석

[조건부 서식]
- 특정 조건 셀 강조
- 데이터막대·색조·아이콘

[단축키]
- Ctrl+C/V/X: 복사·붙여넣기·잘라내기
- Ctrl+Z/Y: 실행취소·재실행
- Ctrl+F/H: 찾기·바꾸기
- Ctrl+Shift+L: 필터 토글
- F4: 절대참조 토글 ($)
- Alt+=: 자동합계

=== 4. 셀 참조 3종 ===

[상대참조]
- A1
- 복사 시 상대적 위치 변화

[절대참조]
- $A$1
- 복사해도 고정

[혼합참조]
- $A1 (열 고정) / A$1 (행 고정)
- 표 참조에서 유용

=== 5. 정보 검색·처리 ===

[검색 연산자]
- AND: 두 키워드 모두 포함
- OR: 둘 중 하나 포함
- NOT (-): 제외
- "": 완전일치
- 예: "금융 AI" -보험

[인터넷 기본]
- HTTP vs HTTPS (암호화)
- 쿠키·세션
- IP 주소·DNS

[자료 신뢰성 평가]
- 출처의 공신력
- 최신성
- 데이터 근거 제시 여부

=== 6. 데이터베이스 기초 ===

[관계형 DB]
