금융·경제 수학 스킬

=== 1. 단리 vs 복리 ===

[단리 Simple Interest]
- 공식: FV = PV × (1 + r × n)
- 원금에만 이자 계산
- 예: 100만원, 연 5%, 3년 → 100 × (1+0.05×3) = 115만원

[복리 Compound Interest]
- 공식: FV = PV × (1 + r)^n
- 이자에도 이자 붙음
- 예: 100만원, 연 5%, 3년 → 100 × (1.05)^3 = 115.76만원

[연 복리 vs 월 복리]
- 연 복리: (1 + r)^n
- 월 복리: (1 + r/12)^(12n)
- 월 복리가 최종 금액 더 큼

=== 2. 현재가치 / 미래가치 ===

[미래가치 FV Future Value]
- 현재 돈의 미래 가치
- FV = PV × (1 + r)^n

[현재가치 PV Present Value]
- 미래 돈의 현재 가치
- PV = FV ÷ (1 + r)^n
- 할인(discount)한다고 표현

[순현재가치 NPV]
- NPV = 미래 현금흐름의 현재가치 - 초기 투자
- NPV > 0 이면 투자가치 있음

=== 3. 단일 원금 - 시점별 시나리오 ===

표기: P=원금, r=연이자율, FV=수령액
전제: 연 1회 복리, 중도해지 수수료·세금 무시

[A1. n년 만기 정상 수령]
- FV = P × (1+r)^n

[A2. n년 만기 상품, m년 시점 중도해지]
- FV = P × (1+r)^m
- 핵심: 경과 년수만큼만 복리 적용
- 기출 패턴: 1.04^19, 1.04^20 값 주고 19년 시점 수령

[A3. n년 만기 후 k년 추가 거치 (자동재예치)]
- FV = P × (1+r)^(n+k)

[A4. n년 만기 후 출금 미이행 (무이자)]
- FV = P × (1+r)^n (증가 없음)

[A5. 지금 받기 vs 나중 받기 비교]
- 지금 P vs n년 후 Q
- Q의 현재가치 = Q / (1+r)^n
- P > Q/(1+r)^n → 지금이 이득
- "올해 바로 수령 vs m년 후 수령" 유형

[A6. 특정 시점 T 시점 가치 환산]
- t=0(현재) P → t=T 시점: P × (1+r)^T
- t=T 시점 Q → t=S (S<T) 시점: Q / (1+r)^(T-S)

=== 4. 정기 적립 - 미래가치 (FV) ===

표기: A=매회 납입액, n=납입횟수, r=회당 이자율

[B1. 매년 말 납입 (후급, ordinary annuity)]
- FV = A × [(1+r)^n - 1] / r
- 마지막 회 납입 직후 시점 가치

[B2. 매년 초 납입 (선급, annuity due)]
- FV = A × [(1+r)^n - 1] / r × (1+r)
- 후급보다 (1+r)배 큼

[B3. 매월 납입 (월복리)]
- 월이자율 = r/12, 개월수 n으로 치환
- FV = A × [(1+r/12)^n - 1] / (r/12)

=== 5. 정기 수령 - 현재가치 (PV) ===

표기: C=매회 수령액, n=수령횟수, r=할인율

[C1. 매년 말 수령 (후급)]
- PV = C × [1 - (1+r)^(-n)] / r
- = C × [(1+r)^n - 1] / [r × (1+r)^n]

[C2. 매년 초 수령 (선급)]
- PV = C × [1 - (1+r)^(-n)] / r × (1+r)
- "올해부터 바로 수령" = 선급 연금

[C3. 영구 수령 (perpetuity)]
- PV = C / r
- 예: 연 100만원 영구, r=5% → PV = 2,000만원

=== 6. 시나리오별 공식 선택 ===

| 상황 | 공식 |
|---|---|
| 일시금 → n년 후 가치 | P × (1+r)^n |
| 일시금 → m년 시점 중도해지 | P × (1+r)^m |
| 매년 말 적립 → n년 후 | A × [(1+r)^n-1]/r |
| 매년 초 적립 → n년 후 | A × [(1+r)^n-1]/r × (1+r) |
| 매년 말 수령 → 현재가치 | C × [1-(1+r)^(-n)]/r |
| 매년 초 수령 → 현재가치 | 후급 PV × (1+r) |
| 지금 vs n년 후 큰 거 고르기 | Q/(1+r)^n 과 P 비교 |

=== 7. 함정 체크리스트 ===

1. **시점 구분**: "만기" vs "중도해지" vs "만기 후 거치"
   - 만기 = 정상 (1+r)^n
   - 중도해지 m년 = (1+r)^m
   - 거치 k년 추가 = (1+r)^(n+k)

2. **선급 vs 후급**: "매년 초" 한 글자 차이로 × (1+r)

3. **주어진 값 선택**: 1.04^19=2.11, 1.04^20=2.19 중
   - 경과 년수에 정확히 매칭되는 걸 골라야 함

4. **단리 trap**: 오답 선지에 P(1+rn) 값 배치됨


=== 4. 72의 법칙 ===

원금이 2배 되는 데 걸리는 기간 ≈ 72 ÷ 금리(%)

예시:
- 금리 6% → 12년에 2배
- 금리 8% → 9년에 2배
- 금리 4% → 18년에 2배

근사 원리: ln(2) ≈ 0.693, 연속복리로 변환 시

=== 5. 수익률 계산 일반화 ===

표기: P₀=매수가, P₁=매도가, D=배당/이자, r=수익률

[A. 단순 자본수익률]
- r = (P₁ - P₀) / P₀
- 매수→매도 차익만 (배당 미포함)

[B. 총수익률 Total Return]
- r = (P₁ - P₀ + D) / P₀
- 배당·이자 포함

[C. 배당수익률 Dividend Yield]
- 배당수익률 = 연 배당금 / 현재 주가
- 채권은 이자수익률 (쿠폰/가격)

[D. 기간 환산 (단순)]
- n개월 수익률 r → 연환산 = r × (12/n)
- 3개월 5% → 연 20% (근사, 복리 무시)

[E. 기간 환산 (복리)]
- 월 수익률 r → 연: (1+r)¹² - 1
- 일 수익률 r → 연: (1+r)³⁶⁵ - 1
- 단순 환산보다 크게 나옴

[F. 명목 vs 실질 (피셔방정식)]
- 근사: 실질 ≈ 명목 - 인플레율
- 정확: (1+명목) = (1+실질)(1+기대인플레)
- → 실질 = (1+명목)/(1+인플레) - 1

[G. 세후 수익률]
- 세후 = 세전 × (1 - 세율)
- 예: 명목 5%, 이자세 15.4% → 세후 4.23%

[H. CAPM (자본자산가격결정)]
- E(R) = Rf + β × (Rm - Rf)
- Rf: 무위험수익률, Rm: 시장수익률, β: 베타
- 예: Rf 3%, Rm 8%, β 1.2 → E(R) = 3 + 1.2×5 = 9%

[I. 포트폴리오 가중평균 수익률]
- Rp = Σ(wᵢ × rᵢ)
- 예: 주식 60%@10% + 채권 40%@3% → 0.6×10 + 0.4×3 = 7.2%

[J. 연평균 수익률 (기하평균, CAGR)]
- CAGR = (최종/초기)^(1/n) - 1
- n년간 총수익률 → 연평균
- 산술평균보다 항상 작거나 같음

=== 6. 환율 계산 일반화 ===

표기: 원/달러 (KRW/USD) = 1,400 → 1달러 = 1,400원

[A. 환율 표기 방식]
- 직접표시 (한국 관행): 1달러 = 1,400원
- 간접표시: 1원 = 1/1,400 달러
- 환율 상승 = 원화 약세 = 달러 강세 (숫자 커짐)
- 환율 하락 = 원화 강세 = 달러 약세

[B. 교차환율]
- EUR/KRW = EUR/USD × USD/KRW
- 예: EUR/USD=1.1, USD/KRW=1,400 → EUR/KRW=1,540

[C. 환전 계산]
- 원 → 달러: 원화 금액 ÷ 환율
- 달러 → 원: 달러 금액 × 환율
- 예: 1,400만원 ÷ 1,400 = 1만 달러

[D. 환차손익 (투자 관점)]
- 매입환율 E₀, 매도환율 E₁, 달러 수량 Q
- 환차익 = (E₁ - E₀) × Q
- 예: $1만 @ 1,400 매입 → @ 1,500 매도 → 이익 100만원

[E. 수출기업 시나리오]
- 수출대금 $ 수령 → 원화 환전
- 환율 상승 = 원화 환산액 ↑ = 수출기업 유리
- 예: 수출 $100만, 환율 1,400→1,500 → 14억→15억 (1억 이익)

[F. 수입기업 시나리오]
- 수입대금 $ 지급 → 원화 필요
- 환율 상승 = 원화 지출액 ↑ = 수입기업 불리
- 예: 수입 $100만, 환율 1,400→1,500 → 지출 14억→15억 (1억 추가)

[G. 외화예금 / 외화대출]
- 외화예금: 환율↑ 유리 (원화 환산 시 이득)
- 외화대출: 환율↑ 불리 (원화 상환 부담 ↑)

[H. 환율 변동률]
- 변동률 = (E₁ - E₀) / E₀ × 100
- 예: 1,400 → 1,470 → +5% (원화 5% 약세)

[I. 원화 강세 = 원화 절상]
- 예: 1,400 → 1,340 → 환율 약 4.3% 하락
- 원화 가치: 1,400원에서 샀던 1달러가 1,340원
- 원화 기준 구매력 ↑

[J. 외환스왑 / 선물환]
- 선물환율 = 현물환율 × (1 + 국내금리) / (1 + 해외금리)
- 고금리국 통화는 선물환에서 디스카운트
- 이자율 평형조건 (IRP)

=== 7. 퍼센트 변화 함정 ===

[A. 감소율 vs 증가율 비대칭]
- 100 → 80: 20% 감소
- 80 → 100: 25% 증가 (40% 아님)
- 공식: (새값 - 원값) / 원값

[B. 연속 변동]
- +10% → -10% ≠ 원상복귀
- 100 → 110 → 99 (1% 감소)
- 복리적 사고 필요

[C. 가중평균]
- 가중평균 = Σ(값 × 가중치) ÷ Σ가중치
- 예: A 70점(가중 60%), B 80점(가중 40%) → 70×0.6 + 80×0.4 = 74

[D. 평균의 함정]
- 단순평균 ≠ 가중평균
- 수익률은 기하평균이 정확 (CAGR)
