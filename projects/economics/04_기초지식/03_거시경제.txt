거시경제 기초

=== 1. GDP / GNI / GNP ===

[GDP 국내총생산]
- "영토" 기준 생산액
- 외국인이 한국에서 번 소득 포함
- 한국 해외법인 소득 제외

[GNI 국민총소득]
- "국민" 기준 소득
- 해외서 번 소득 포함
- 외국인 국내 소득 제외
- 공식: GDP + 해외 순수취요소소득

[GNP 국민총생산]
- 과거 지표, 현재는 GNI로 대체

[실질 vs 명목]
- 명목 GDP: 당해년 가격
- 실질 GDP: 기준연도 가격 (인플레이션 제거)
- GDP 디플레이터 = 명목GDP / 실질GDP × 100

=== 2. 인플레이션 ===

[물가지수]
- CPI (소비자물가): 가계 구매 재화·서비스
- PPI (생산자물가): 기업 생산단계 물가
- 근원물가 (Core CPI): 식료품·에너지 제외

[인플레이션 종류]
- 수요견인형 (Demand-pull): 총수요 증가
- 비용인상형 (Cost-push): 원가 상승 (원유 등)
- 스태그플레이션: 경기침체 + 물가상승 동시

[실질 vs 명목 이자율]
- 피셔방정식: 명목 = 실질 + 기대인플레
- 실질이자율 < 0 이면 "저축 손해"

=== 3. 통화량 ===

[본원통화]
- 중앙은행이 발행한 화폐 (현금 + 지준)

[M1 협의통화]
- 현금 + 요구불예금
- 즉시 사용 가능

[M2 광의통화]
- M1 + 만기 2년 미만 예적금·금융상품

[Lf 금융기관유동성]
- M2 + 만기 2년 이상 금융상품

[L 광의유동성]
- Lf + 국채·회사채 등

[통화승수]
- M2 / 본원통화
- 신용창출 정도 (은행의 대출·예금 반복)

=== 4. 실업 ===

[실업률]
- 실업자 ÷ 경제활동인구 × 100
- 경제활동인구 = 취업자 + 실업자
- 비경활 제외 (학생, 주부 등)

[실업 종류]
- 마찰적: 이직·구직 중 일시적 (정상적)
- 구조적: 산업구조 변화 (기술 불일치)
- 경기적: 경기침체로 발생
- 계절적: 농업·관광 등 계절 변동

[자연실업률]
- 마찰적 + 구조적 실업률
- 경기와 무관하게 존재

[필립스곡선]
- 인플레이션 ↑ ↔ 실업률 ↓ (단기 역관계)
- 장기에는 성립 안 함 (수직선)

=== 5. 재정정책 vs 통화정책 ===

[재정정책 Fiscal Policy]
- 주체: 정부
- 수단: 정부지출, 세금
- 확장: 지출↑ 세금↓ / 긴축: 지출↓ 세금↑

[통화정책 Monetary Policy]
- 주체: 중앙은행
- 수단: 기준금리, 공개시장운영, 지급준비율
- 확장: 금리↓ / 긴축: 금리↑

[공개시장운영]
- 국채 매입 → 통화량 증가 → 금리 하락
- 국채 매각 → 통화량 감소 → 금리 상승

=== 6. 환율 결정 이론 ===

[구매력평가설 PPP]
- 양국 물가비율로 환율 결정
- 빅맥지수 (PPP 적용 예)

[금리평가설 IRP]
- 양국 금리차로 환율 결정
- 고금리 통화는 선물환 할인

[환율 상승 영향]
- 수출 경쟁력 ↑ (원화 가치 ↓)
- 수입물가 ↑ → 인플레이션
- 외채 부담 ↑

=== 7. 경기지표 ===

[선행지수]
- 미래 경기 예측 (주가, 건축허가)

[동행지수]
- 현재 경기 (산업생산, 취업자수)

[후행지수]
- 과거 경기 (실업률, 재고)

=== 8. 경제지표 계산 일반화 ===

[A. GDP 3면 등가]
- 생산 측면 = 분배 측면 = 지출 측면
- 지출 GDP = C + I + G + (X − M)
  * C 소비, I 투자, G 정부지출, X 수출, M 수입

[B. 명목 GDP vs 실질 GDP]
- 명목 GDP = Σ(당해 가격 × 당해 생산량)
- 실질 GDP = Σ(기준연도 가격 × 당해 생산량)
- 실질 GDP 성장률 = 실제 경제 성장

[C. GDP 디플레이터]
- 디플레이터 = 명목GDP / 실질GDP × 100
- 물가 변동 지표 (GDP 포괄 → CPI보다 광범위)
- 예: 명목 3,000조, 실질 2,500조 → 디플레이터 120

[D. 경제성장률]
- 성장률 = (금년 실질GDP − 전년 실질GDP) / 전년 실질GDP × 100
- 예: 2,500 → 2,547.5 → 1.9% (2026 전망)

[E. 1인당 GDP]
- 1인당 GDP = GDP ÷ 총인구
- 1인당 GNI = GNI ÷ 총인구 (국민 복지 지표)

[F. 실업률·고용률·참가율]
- 생산가능인구 (15세 이상) = 경제활동인구 + 비경제활동인구
- 경제활동인구 = 취업자 + 실업자

| 지표 | 공식 |
|---|---|
| 실업률 | 실업자 / 경제활동인구 × 100 |
| 고용률 | 취업자 / 생산가능인구 × 100 |
| 경제활동참가율 | 경제활동인구 / 생산가능인구 × 100 |

함정: 분모가 다름 (실업률은 경활인구, 고용률은 생산가능인구)

[G. 물가상승률 (CPI 기반)]
- CPI 상승률 = (금년 CPI − 전년 CPI) / 전년 CPI × 100
- 예: CPI 110 → 113.3 → +3%

[H. 실질임금·실질이자율]
- 실질임금 = 명목임금 / 물가지수 × 100
- 실질이자율 = 명목이자율 − 기대인플레 (피셔 근사)
- 정확식: (1+명목) = (1+실질)(1+인플레)

[I. 통화승수]
- M2 = 본원통화 × 통화승수
- 통화승수 = 1 / 지급준비율 (단순 모형)
- 예: 지준율 10% → 승수 10배

[J. 국제수지]
- 경상수지 = 상품수지 + 서비스수지 + 본원소득수지 + 이전소득수지
- 자본수지 + 금융계정
- 전체 = 0 (복식부기 원리)

[K. GNI vs GDP]
- GNI = GDP + 해외 순수취요소소득
- 해외 순수취 = 해외서 번 소득 − 외국인이 국내서 번 소득

[L. 필립스곡선 수치 해석]
- 단기: 물가 1%p ↑ → 실업률 ~0.5%p ↓ (오쿤의 법칙과 연계)
- 장기: 수직선 (자연실업률 고정)

[M. 오쿤의 법칙]
- GDP 갭 2% = 실업률 1%p 차이 (대략)
- 경기침체 정도 가늠

=== 9. 거시 모형 확장 ===

[A. 필립스곡선 (단기 vs 장기)]

단기 필립스곡선:
- π = πᵉ − α(u − uₙ)
  * π: 실제 인플레, πᵉ: 기대인플레
  * u: 실제 실업률, uₙ: 자연실업률
  * α: 반응계수
- 우하향 (실업 ↓ ↔ 물가 ↑)

장기 필립스곡선:
- 수직선 (자연실업률 uₙ 고정)
- 통화정책으로 장기 실업률 조정 불가
- 스태그플레이션이 이를 입증 (1970s)

[B. 오쿤의 법칙 Okun's Law]
- 실제 GDP − 잠재 GDP = -α × (u − uₙ) × 잠재GDP
- 간이형: 실업률 1%p ↑ → 실질 GDP ~2% ↓
- 경기침체 정도 가늠
- 성장률과 실업률 역관계

[C. AD-AS 모형]

총수요 AD (우하향):
- AD = C + I + G + (X − M)
- 물가 ↑ → 실질통화량 ↓ → 이자율 ↑ → I ↓

총공급 AS:
- 단기 AS: 우상향 (임금 경직성)
- 장기 AS: 수직 (잠재GDP)

균형:
- AD = AS
- 수요충격: AD 이동
- 공급충격: AS 이동 (석유파동, 스태그플레이션)

[D. IS-LM 모형]

IS곡선 (실물시장):
- 투자 = 저축 균형
- 우하향 (이자율 ↓ → 투자 ↑ → 소득 ↑)

LM곡선 (화폐시장):
- 화폐수요 = 화폐공급 균형
- 우상향 (소득 ↑ → 화폐수요 ↑ → 이자율 ↑)

교차점:
- 이자율·소득 동시 결정
- 재정정책: IS 이동
- 통화정책: LM 이동

[E. 솔로우 성장모형]

핵심식:
- Y = F(K, L) (자본·노동)
- 저축률 s, 감가상각 δ
- k* 정상상태: sf(k*) = (n + δ)k*

시사점:
- 저축률 ↑ → 1인당 소득 수준 ↑ (일시적)
- 기술진보만이 장기 성장 원천
- 자본의 한계수익 체감

[F. 총수요 승수효과]

정부지출 승수:
- ΔY/ΔG = 1/(1-MPC) (폐쇄경제)
- MPC: 한계소비성향
- 예: MPC = 0.8 → 승수 5

조세승수:
- ΔY/ΔT = -MPC/(1-MPC)
- 예: MPC = 0.8 → 조세승수 -4

균형재정승수 = 1 (정부지출↑ + 세금↑ 동일 규모)

[G. 인플레이션 기대 (합리적 기대)]

적응적 기대:
- 과거 경험에 기반
- 필립스곡선 단기 유효

합리적 기대 (Lucas):
- 모든 정보 활용, 체계적 오류 없음
- 예측된 정책은 효과 없음 (정책무력성)

[H. 본원통화·신용창출]

본원통화 B = 현금 C + 지급준비금 R

통화공급 M = C + D (D: 예금)

통화승수 m = M/B
  = (C/D + 1) / (C/D + R/D)

예: 현금비율 10%, 지준율 10% → 승수 ≈ 5.5배

[I. 피셔효과·기대인플레]
- 명목이자 = 실질이자 + 기대인플레
- 기대인플레 ↑ → 명목금리 ↑
- 장기에서 실질이자율 불변 가정

[J. 자본유출입·환율]
- 국내금리 ↑ → 자본유입 → 환율 ↓ (원화강세)
- 국내금리 ↓ → 자본유출 → 환율 ↑ (원화약세)
- 트릴레마: 자본이동·고정환율·독립통화정책 중 2개만

[K. 먼델-플레밍 모형 (개방경제)]
- 변동환율 + 자본이동: 통화정책 효과적, 재정정책 무력
- 고정환율 + 자본이동: 재정정책 효과적, 통화정책 무력
