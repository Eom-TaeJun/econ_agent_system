# eco_system_v2

이 시스템은 VIX·S&P500·금리·국채·달러·원유·구리·하이일드채권 등 거시경제 데이터를 실시간으로 수집한 뒤 서로 다른 관점의 AI 에이전트들이 독립적으로 분석하고 토론을 거쳐 투자 신호에 합의하는 구조다. Claude 기반 에이전트는 거시경제를 종합 해석하고 Perplexity 기반 에이전트는 최신 뉴스와 리서치를 검색하며 정량 에이전트는 LLM 없이 레짐 탐지와 리스크 측정과 LASSO 예측을 수행한다. 이 세 에이전트가 병렬로 각자 신호를 낸 뒤 악마의 변호인 역할의 토론 에이전트가 그 결과에 반론을 제기한다. 최종 합의는 단순 다수결이 아닌 신뢰도 가중 투표로 이루어지며 누가 어떤 근거로 동의했고 반대했는지 그리고 마진과 신뢰도가 어떻게 산출되었는지를 전부 투명하게 출력한다. 합의 결과를 바탕으로 시장 레짐에 따른 자산 배분을 추천하고 과거 분석 이력과 비교해 신호의 방향 변화와 연속성도 추적한다. 모든 판단 기준이 되는 임계값에는 학술 논문이나 시장 데이터 등 근거를 명시해 시스템의 판단이 납득 가능하도록 설계했다.
