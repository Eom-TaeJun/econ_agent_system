GFSI (Global Fear & Stress Index) 설명서
=========================================

1. 이게 뭔가요?
-----------------

VIX라는 지표를 아시나요? "공포 지수"라고 불리는, 미국 주식시장의 불안감을
숫자로 보여주는 지표입니다.

그런데 VIX에는 한계가 있습니다.

  - 미국 주식 옵션만 봅니다.
  - 미국 장이 닫으면(밤, 주말, 공휴일) 아무것도 반영 못합니다.
  - 크립토, 전쟁, 환율 급변 같은 건 장이 열려야 뒤늦게 반영됩니다.

GFSI는 이 빈틈을 채우기 위해 만든 지표입니다.
비트코인은 24시간 거래되고, 유가 선물도 거의 24시간,
환율도 주중에는 거의 쉬지 않습니다.

이런 24/7 데이터를 묶어서 "지금 세계가 얼마나 불안한가"를
하나의 숫자(0~100)로 보여주는 게 GFSI입니다.


2. 점수는 어떻게 읽나요?
-------------------------

0점에 가까울수록 → 세계가 불안하다 (공포, 자본 이탈)
100점에 가까울수록 → 세계가 안정적이다 (낙관, 자본 유입)

구간별로 이름을 붙였습니다:

   0~20   CRISIS     극단적 공포. 여러 채널이 동시에 경고.
  20~40   STRESS     스트레스. 주의 필요.
  40~60   NEUTRAL    중립. 특별한 방향성 없음.
  60~80   EXPANSION  확장. 자본이 유입되고 변동성이 낮음.
  80~100  EUPHORIA   과열. 너무 낙관적이라 역으로 조심해야 할 수 있음.


3. 무엇을 보나요? (6개 채널)
-----------------------------

GFSI는 6개 영역("채널")을 각각 따로 점수 매긴 뒤 합칩니다.

┌─────────────────────────────────────────────────────────────────┐
│  채널 1. 크립토 변동성 (비중 20%)                               │
│                                                                 │
│  뭘 보나: 비트코인의 최근 변동성이 평소보다 높은지              │
│  왜 보나: 비트코인은 24시간 거래. 주말에 BTC가 급락하면         │
│           월요일 주식시장도 갭다운으로 시작하는 경우가 많음.     │
│  데이터:                                                        │
│    - BTC 20일 변동성 ÷ 60일 변동성 (비율이 높으면 스트레스)     │
│    - BTC 7일 수익률                                             │
│    - ETH/BTC 비율 변화 (알트코인 강세 = 위험선호)               │
│                                                                 │
│  예시:                                                          │
│    BTC가 일주일간 안정적 → 72점 (안정)                          │
│    BTC가 이틀만에 10% 급락 → 25점 (스트레스)                    │
│    BTC 횡보하는데 ETH가 상대 강세 → 65점 (리스크 온)            │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  채널 2. 스테이블코인·DeFi 흐름 (비중 15%)                      │
│                                                                 │
│  뭘 보나: 달러와 연동된 코인(USDC, USDT)의 발행량 변화,        │
│           탈중앙금융(DeFi)에 묶인 자금(TVL) 변화                │
│  왜 보나: 스테이블코인 발행이 늘면 = 현금이 크립토로 들어옴.   │
│           DeFi TVL이 늘면 = 온체인에서 돈이 돌고 있음.          │
│           이건 전통 금융 데이터에 전혀 안 잡힘.                  │
│  데이터:                                                        │
│    - 스테이블코인 총 시가총액 7일 변화율                         │
│    - DeFi TVL(총 예치금) 7일 변화율                             │
│                                                                 │
│  예시:                                                          │
│    USDC 대량 발행 + TVL 증가 → 90점 (자본 유입)                 │
│    스테이블코인 유출 + TVL 감소 → 10점 (패닉 이탈)              │
│    소폭 유출이지만 TVL은 증가 → 55점 (혼재)                     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  채널 3. 지정학 스트레스 (비중 20%)                              │
│                                                                 │
│  뭘 보나: 유가와 금이 동시에 오르는지                           │
│  왜 보나: 전쟁이나 제재가 터지면 유가(에너지 불안)와            │
│           금(안전자산 수요)이 동시에 급등합니다.                 │
│           둘 다 24시간 선물 거래가 가능해서 즉시 반응합니다.     │
│           반면 유가만 오르고 금은 안 오르면 → 단순 공급 문제.   │
│  데이터:                                                        │
│    - 유가-금 20일 수익률 상관계수 (동조 vs 디커플링)             │
│    - 유가 7일 변화율                                            │
│    - 금 가격 vs 20일 이동평균                                   │
│                                                                 │
│  예시:                                                          │
│    유가+금 동시급등 (상관 0.7) → 8점 (지정학 위기)               │
│    유가만 급등, 금 하락 (상관 -0.2) → 60점 (공급 이슈)           │
│    둘 다 안정 → 85점 (평화로운 시기)                             │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  채널 4. 통화 스트레스 (비중 15%)                                │
│                                                                 │
│  뭘 보나: 달러와 엔화의 급격한 움직임                           │
│  왜 보나: 달러가 갑자기 강해지면 신흥국과 원자재 시장이 타격.   │
│           엔화가 갑자기 강해지면 "캐리 트레이드" 해소가 일어나   │
│           글로벌 위험자산이 동시에 매도됩니다.                   │
│           (2024년 8월 일본 금리인상 → 글로벌 급락 사례)          │
│           핵심: 양방향 급변 모두 나쁨. 안정이 좋은 것.           │
│  데이터:                                                        │
│    - 달러인덱스(DXY) 20일 변화율 (절대값)                       │
│    - USD/JPY 20일 변화율 (방향별 비대칭 처리)                    │
│                                                                 │
│  예시:                                                          │
│    DXY, JPY 모두 변화 미미 → 90점 (안정)                        │
│    엔화 급강세 -5% (캐리 붕괴) → 15점 (위기)                    │
│    달러 +4.5% 급등 → 38점 (스트레스)                             │
│                                                                 │
│  비대칭 처리란?                                                  │
│    엔 강세(= 캐리 해소)가 엔 약세보다 더 위험하게 취급됩니다.   │
│    캐리 트레이드 해소는 글로벌 자산을 한꺼번에 흔들기 때문.     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  채널 5. 시장 심리 (비중 15%)                                    │
│                                                                 │
│  뭘 보나: 크립토 Fear & Greed 지수                              │
│  왜 보나: 소셜미디어, 거래량, 변동성, 트렌드를 종합한           │
│           심리 지표. 0이면 극단 공포, 100이면 극단 탐욕.         │
│           24시간 업데이트되므로 주말에도 심리를 볼 수 있음.      │
│  데이터:                                                        │
│    - Fear & Greed Index 현재값 (0~100)                          │
│    - 7일 추세 (개선 중인지 악화 중인지로 ±5점 보정)             │
│                                                                 │
│  예시:                                                          │
│    Fear & Greed 15, 추세 악화 → 12점 (극단 공포)                │
│    Fear & Greed 45, 추세 개선 → 50점 (중립)                     │
│    Fear & Greed 85, 추세 상승 → 90점 (과열 경고)                │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  채널 6. 유동성 (비중 15%)                                       │
│                                                                 │
│  뭘 보나: 미국 연준의 실질 유동성 지표 (RRP, TGA)               │
│  왜 보나: 시장에 돈이 많으면 자산가격이 오르고,                 │
│           돈이 빠지면 자산가격이 떨어집니다.                     │
│    - RRP(역환매조건부채권): 은행이 연준에 맡긴 돈.              │
│      줄어들면 → 그 돈이 시장으로 풀림 → 긍정.                   │
│    - TGA(재무부 일반계좌): 정부가 쌓아둔 현금.                  │
│      너무 많으면 → 시장에서 돈을 빨아들인 상태 → 부정.          │
│  데이터:                                                        │
│    - RRP 7일 변화율                                             │
│    - TGA 잔고 (적정 수준 ~5000억 달러 기준 편차)                │
│                                                                 │
│  예시:                                                          │
│    RRP 감소 + TGA 적정 → 100점 (유동성 넘침)                    │
│    RRP 증가 + TGA 높음 → 0점 (유동성 경색)                      │
└─────────────────────────────────────────────────────────────────┘


4. 어떻게 합치나요?
--------------------

각 채널 점수에 비중(가중치)을 곱해서 더합니다.

  GFSI = 크립토×20% + 스테이블×15% + 지정학×20%
       + 통화×15% + 심리×15% + 유동성×15%

실제 예시 (2026년 3월 19일):

  크립토 변동성:  72점 × 20% =  14.4
  스테이블 흐름:  55점 × 15% =   8.3
  지정학:         60점 × 20% =  12.0
  통화:           28점 × 15% =   4.2
  심리:           27점 × 15% =   4.1
  유동성:         66점 × 15% =   9.9
  ─────────────────────────────────
  합계:                        52.8점 → NEUTRAL

같은 날 VIX는 25.1 ("경계" 수준).
VIX만 보면 불안하지만, GFSI는 52.8으로 중립.

왜 차이가 나나?
  VIX가 못 보는 것:
    ✓ 비트코인 변동성은 오히려 안정적 (72점)
    ✓ 연준 유동성도 풍부한 편 (66점)
  VIX에 아직 안 반영됐을 수 있는 것:
    ✗ 통화 시장 긴장 (28점) — 엔화가 3% 임계값 직전
    ✗ 크립토 심리 극단 공포 (27점) — 선행 경고?


5. 이걸로 뭘 하려는 건가요?
-----------------------------

단순히 숫자를 만드는 게 목적이 아닙니다.
매일 기록하면서 다음을 검증합니다:

  (1) 선행성 검증
      "크립토 변동성이 급등한 뒤 며칠 후에 VIX도 올랐나?"
      "스테이블코인이 빠지면 주식시장도 며칠 뒤에 빠지나?"
      → 각 채널이 VIX를 며칠 앞서는지 통계적으로 측정

  (2) 이중반영 필터링
      "유가 급등이 이미 VIX에 반영됐다면,
       GFSI에서 이중으로 세는 건 아닌가?"
      → 각 채널이 VIX로 설명되는 비율(R²)을 구해서,
        이미 반영된 부분은 걸러내고 VIX가 못 잡는 잔차만 추출

  (3) 목표별 유의미성
      - 단기 트레이딩 (1~5일): 어떤 채널이 가장 유용한가?
      - 중기 포지셔닝 (1~3개월): 어떤 채널이 가장 유용한가?
      - 테일리스크 경보: 어떤 조합이 큰 하락을 예고했나?

  (4) 실제 수익률과 비교
      "GFSI가 30점 이하일 때 30일 후 BTC는 얼마나 올랐나?"
      → 점수의 실제 예측력을 검증


6. 구체적으로 뭐가 바뀌면 점수가 어떻게 변하나요?
--------------------------------------------------

아래는 각 채널별로 "이런 일이 생기면 이렇게 변한다"는 예시입니다.

■ 시나리오 A: 주말에 BTC 10% 급락
  크립토 변동성: 72점 → 약 25점 (변동성 비율 급등 + 수익률 급락)
  심리:         27점 → 약 12점 (F&G 추가 하락)
  다른 채널:    변화 없음 (주말이라 전통시장 데이터 갱신 안 됨)
  GFSI:         52.8 → 약 40점 (STRESS로 하락)
  → 월요일 장 열기 전에 이미 경고 발생

■ 시나리오 B: 중동 전쟁 발발
  지정학:   60점 → 약 8점 (유가+금 동시급등, 상관 0.7+)
  통화:     28점 → 약 20점 (달러 급등)
  심리:     27점 → 약 15점 (공포 확산)
  유동성:   변화 적음
  크립토:   변동성에 따라 다름
  GFSI:     52.8 → 약 30점 (STRESS)

■ 시나리오 C: 연준이 금리를 내리고 유동성 공급
  유동성:   66점 → 약 90점 (RRP 감소, TGA 적정화)
  통화:     28점 → 약 60점 (달러 약세로 안정 방향)
  심리:     27점 → 약 50점 (심리 개선)
  GFSI:     52.8 → 약 68점 (EXPANSION)

■ 시나리오 D: 2024년 8월 일본발 급락 재현
  통화:     28점 → 약 10점 (엔 급강세 -5%, 캐리 언와인딩)
  크립토:   72점 → 약 30점 (BTC 동반 급락)
  심리:     27점 → 약 8점 (극단 공포)
  GFSI:     52.8 → 약 28점 (STRESS, CRISIS 근접)


7. 한계와 주의사항
-------------------

  - 이 지표는 실험 단계입니다.
    모든 임계값(예: "유가 ±10% 범위")은 아직 백테스트를 거치지 않았습니다.
    20일 이상 데이터가 쌓인 뒤 통계적 검증을 시작합니다.

  - 각 채널의 비중(20%, 15% 등)은 현재 고정값입니다.
    향후 시장 환경(레짐)에 따라 자동 조정되는 적응형으로 전환할 예정입니다.

  - 투자 조언이 아닙니다.
    "GFSI가 낮으니 매수하라"는 식의 결론을 내리는 도구가 아니라,
    "VIX가 놓치는 리스크가 있는지" 확인하는 보조 시야를 제공합니다.


8. 요약
--------

  기존 VIX:  미국 주식 옵션 → 장 시간에만 → 사후 반영
  GFSI:      크립토+유가+금+환율+심리+유동성 → 24/7 → 선행 가능성

  만든 이유: VIX가 눈 감은 시간대의 리스크를 포착하고,
             각 채널이 실제로 VIX보다 앞서는지 매일 검증하기 위해.

  최종 목표: "어떤 채널이, 어떤 상황에서, 며칠 앞서 경고하는가"를
             데이터로 증명하는 것.
