# Rubric (총 100점)

## 1) 데이터 진단과 전처리 설계 (25점)
- 25점: 타입/중복/결측/이상치 진단이 완전하고 처리 전략 근거가 명확하며, 분포 진단(skewness/Q-Q plot/정규성 검정)이 포함됨
- 20점: 핵심 진단은 수행했으나 분포 진단 또는 일부 근거가 부족함
- 14점: 진단 항목이 누락되거나 전략 선택이 임의적임
- 7점: 진단을 시도했으나 대부분 불완전함
- 0점: 전처리 과정 설명 없음

## 2) 결측치/이상치 처리 실행 + 통계적 검증 (25점)
- 25점: 최소 2개 이상 전략 비교, 전/후 변화 정량 보고, 가설 검정(p-value) + 효과 크기(Cohen's d) 보고, 코드 재현 가능
- 20점: 전략 비교와 정량 보고는 했으나 가설 검정 또는 효과 크기 중 하나가 누락
- 14점: 단일 전략만 적용하거나 비교가 부실하며 통계 검정 없음
- 7점: 처리를 시도했으나 결과 보고가 미흡함
- 0점: 처리 미수행

## 3) 시각화 품질과 전/후 비교 명확성 (20점)
- 20점: 그래프가 질문에 직접 답하며 축/단위/범례가 일관됨
- 15점: 그래프 수는 충분하나 비교 설계가 일부 불명확함
- 10점: 그래프는 있으나 해석 연결성이 약함
- 5점: 그래프가 최소 요건 미달이나 일부 존재
- 0점: 필수 그래프 부족

## 4) 해석과 스토리텔링 (20점)
- 20점: 인사이트 3개가 데이터 근거와 운영 제안으로 연결됨
- 15점: 인사이트는 있으나 실행 제안 또는 근거가 약함
- 10점: 요약 위주이며 의사결정 문장 부족
- 5점: 해석을 시도했으나 근거가 거의 없음
- 0점: 해석 미제출

## 5) 재현성과 문서화 (10점)
- 10점: 파일 구조, 실행 순서, 결과 설명이 명확해 재현 가능
- 7점: 대체로 재현 가능하나 일부 누락 존재
- 4점: 실행 순서/환경 설명 부족
- 0점: 재현 불가

## 감점 기준
- 전/후 비교 그래프 축 불일치: -3점
- 핵심 지표(행 수/결측률/평균/중앙값/IQR) 누락: -5점
- 근거 없는 임의 임계값 사용: -3점
- 도메인 규칙 위반 점검 미수행 (예: 음수 대여량 확인 없이 IQR만 적용): -3점
- 정규성 검정 없이 모수 검정(t-test) 사용: -2점
- 전/후 비교에서 가설 검정(p-value) 또는 효과 크기 누락: -3점
- 상관계수 보고 시 유의성(p-value) 미표기: -2점
