# EDA 실습 문제지 (초안)

## 1. 실습 목적
- 데이터 전처리, 결측치 처리, 이상치 처리의 필요성을 전/후 비교로 이해한다.
- 시각화 결과를 근거로 분석 결론을 작성한다.

## 2. 실습 데이터
- 기본 파일: `data/raw_dirty.csv`
- 비교 파일(선택): `data/raw_clean.csv`
- 주요 타깃: `Rented Bike Count`

## 3. 과제 문항

### Q1. 데이터 스키마 점검 + 분포 진단
- 변수 타입, 행/열 수, 기초 통계량을 정리한다.
- 타깃 변수의 skewness, kurtosis를 보고하고 Q-Q plot을 그린다.
- 정규성 검정(Shapiro-Wilk)을 수행하여 후속 검정 방법 선택의 근거를 마련한다.

### Q2. 중복 및 타입 오류 점검
- 중복 행, 날짜 파싱 오류, 비정상 범주를 점검하고 수정한다.
- **주의**: 이 단계를 먼저 처리해야 이후 결측치/이상치 분석이 올바르게 작동합니다.
- **힌트**: 범주형 변수의 `value_counts()`를 확인하여 표기 불일치가 있는지 살펴보세요.

### Q3. 결측치 진단
- 변수별 결측 비율을 계산하고 결측 패턴을 시각화한다.

### Q4. 결측치 처리 전략 비교
- `drop`과 `group_median`을 각각 적용하고 전/후 차이를 비교한다.
- **주의**: drop 적용 시 손실 행 수와 손실 비율을 반드시 보고한다.
- **가설 검정**: 처리 전/후 분포 차이에 대해 통계 검정(t-test 또는 Mann-Whitney U)을 수행한다.
- **효과 크기**: Cohen's d를 함께 보고한다.

### Q5. 이상치 탐지
아래 두 단계로 이상치 후보를 식별한다.
1. **도메인 규칙 확인**: 물리적으로 불가능한 값이 있는가? (예: 대여 수 < 0, 강수량 < 0)
2. **통계 기준 적용**: IQR 또는 Z-score로 극단값 식별
- 필수 결과: 박스플롯 + 도메인 규칙 위반 건수 표

### Q6. 이상치 처리 전략 비교
- `remove`와 `cap`을 각각 적용하고 통계량 변화를 비교한다.
- 가설 검정 + Cohen's d를 함께 보고한다.

### Q7. 파생 변수 생성
- 시간대, 주말/평일, 계절 등 파생 변수를 생성한다.

### Q8. 핵심 질문 1
- 질문: 수요 피크 시간은 언제인가?
- 처리 전/후 결과를 같은 축으로 비교한다.

### Q9. 핵심 질문 2
- 질문: 날씨와 수요의 관계는 어떤가?
- 상관/산점도 기반으로 해석하며, 각 상관계수에 p-value를 함께 보고한다.

### Q10. 결론
- 인사이트 3개, 운영 제안 1개, 한계 2개를 작성한다.

## 4. 제출물
1. 분석 노트북 1개
2. 요약 보고서 1개(2~4페이지)
3. 비교 시각화 6개 이상

## 5. 필수 작성 규칙
1. 전/후 비교 그래프는 같은 축 범위를 사용한다.
2. 아래 지표를 숫자로 반드시 보고한다.
- 행 수 변화
- 결측률 변화
- 평균/중앙값 변화
- IQR(또는 표준편차) 변화
3. 전/후 비교에는 가설 검정(p-value)과 효과 크기(Cohen's d)를 함께 보고한다.
4. 상관계수에는 유의성(p-value)을 함께 표기한다.
