# Assignment: EDA and Data Cleaning

## 1) 과제 시나리오
당신은 "공공 자전거 수요 분석"을 맡은 데이터 분석가입니다.
분석 대상 데이터에는 결측치, 이상치, 중복/형식 오류가 섞여 있습니다.
목표는 전처리 전/후를 비교해 신뢰 가능한 인사이트를 도출하는 것입니다.

## 2) 학습 목표

- 전처리가 왜 필요한지 설명할 수 있다.
- 결측치 처리 방법을 상황에 맞게 선택할 수 있다.
- 이상치가 통계와 해석에 주는 영향을 설명할 수 있다.
- 시각화로 전/후 차이를 명확히 전달할 수 있다.

## 3) 제출물

1. 분석 노트북 1개 (`starter` 기반, 함수 구현 포함)
2. 보고서 1개 (2~4페이지)
3. 필수 시각화 6개 이상 (전/후 비교 포함)
4. 방법 선택 근거와 한계 설명

## 4) 과제 문항 (총 10문항)

### 1. 데이터 스키마 점검
- 해야 할 일: 변수 타입, 행/열 수, 기초 통계량 확인
- 왜 필요한가: 전처리 전 상태를 기준선으로 잡기 위해
- 필수 결과: `데이터 프로파일 표` 1개

### 2. 중복 및 타입 오류 점검
- 해야 할 일: 중복 행, 비정상 범주, 날짜/시간 파싱 오류 점검
- 왜 필요한가: 중복과 형식 오류는 집계 결과를 직접 망가뜨리며, 날짜 파싱이 실패하면 후속 시계열 분석과 파생 변수 생성이 불가능하기 때문
- 필수 결과: `문제 건수 표` + `수정 전/후 레코드 예시`
- **주의**: 이 단계를 먼저 처리해야 Q3 이후의 결측치/이상치 분석이 올바르게 작동합니다.

### 3. 결측치 진단
- 해야 할 일: 변수별 결측 비율 계산, 결측 패턴 시각화
- 왜 필요한가: 결측이 랜덤인지 특정 조건에 몰려있는지 확인하기 위해
- 필수 결과: `결측 비율 막대그래프` + `결측 패턴 히트맵`

### 4. 결측치 처리 전략 A/B 비교
- 해야 할 일: 아래 2개 전략을 각각 적용하고 결과 비교
1. 단순 제거(`drop`)
2. 그룹 기반 대체(예: 시간대/요일별 중앙값)
- 왜 필요한가: 처리 방식에 따라 표본 수와 분포가 달라지기 때문
- 필수 결과: `처리 전/후 분포 그래프` + `행 수 변화 표`

### 5. 이상치 탐지
- 해야 할 일: 아래 두 단계로 이상치 후보 식별
  1. **도메인 규칙 확인**: 물리적으로 불가능한 값이 있는가? (예: 대여 수 < 0, 강수량 < 0)
  2. **통계 기준 적용**: IQR 또는 Z-score로 극단값 식별
- 왜 필요한가: 극단값이 평균/분산/상관을 왜곡할 수 있기 때문
- 필수 결과: `박스플롯` + `산점도` (이상치 마킹) + `도메인 규칙 위반 건수 표`

### 6. 이상치 처리 전략 A/B 비교
- 해야 할 일: 아래 2개 전략을 각각 적용하고 결과 비교
1. 이상치 제거
2. 윈저라이징(상하위 임계값으로 절단)
- 왜 필요한가: 제거와 절단은 보존 정보량과 왜곡 감소에서 트레이드오프가 다름
- 필수 결과: `전/후 박스플롯` + `요약통계 변화 표`

### 7. 파생 변수 생성
- 해야 할 일: 시간대 구간, 주말/평일, 계절 등 파생 변수 생성
- 왜 필요한가: 원본 변수만으로는 패턴이 숨겨질 수 있기 때문
- 필수 결과: `파생 변수 정의 표` + `구간별 수요 그래프`

### 8. 핵심 질문 1 분석
- 질문: "수요 피크 시간은 언제인가?"
- 해야 할 일: 처리 전/후 각각 피크 시간 비교
- 필수 결과: `시간대별 라인차트` (전/후 오버레이)

### 9. 핵심 질문 2 분석
- 질문: "날씨(기온/강수/습도)는 수요와 어떤 관계가 있는가?"
- 해야 할 일: 변수 간 관계를 시각화하고 처리 전/후 차이 설명
- 필수 결과: `상관 히트맵` + `기상 변수 vs 수요 산점도`

### 10. 결론 및 권고안
- 해야 할 일: 최종 인사이트 3개, 운영 제안 1개, 분석 한계 2개 제시
- 왜 필요한가: 분석 결과를 의사결정 문장으로 바꾸는 훈련
- 필수 결과: `요약 슬라이드 스타일 페이지` 1장

## 5) 작성 규칙

- 모든 비교 그래프는 같은 축 범위를 사용합니다.
- 숫자 비교 4가지는 반드시 포함합니다.
1. 행 수 변화
2. 결측률 변화
3. 평균/중앙값 변화
4. IQR 또는 표준편차 변화
- "좋아졌다" 같은 모호한 표현 대신 정량 수치를 씁니다.
