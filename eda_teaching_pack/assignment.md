# Assignment: EDA and Data Cleaning

## 1) 과제 시나리오
당신은 "공공 자전거 수요 분석"을 맡은 데이터 분석가입니다.
분석 대상 데이터에는 결측치, 이상치, 중복/형식 오류가 섞여 있습니다.
목표는 전처리 전/후를 비교해 신뢰 가능한 인사이트를 도출하는 것입니다.

## 2) 학습 목표

- 전처리가 왜 필요한지 설명할 수 있다.
- 결측치 처리 방법을 상황에 맞게 선택할 수 있다.
- 이상치가 통계와 해석에 주는 영향을 설명할 수 있다.
- 시각화로 전/후 차이를 명확히 전달할 수 있다.
- 분포를 보고 적절한 검정 방법을 선택할 수 있다.
- 변수 간 관계를 파악하고 중요 변수를 식별할 수 있다.

## 2-b) 기법-목적 매핑표

> "이 기법을 왜 지금 쓰는가?"를 항상 먼저 생각한다.

| 문항 | 목적 (왜 하는가) | 핵심 기법 |
|------|------------------|-----------|
| Q1 | 데이터 상태 파악 + 분포 확인 → 후속 분석 방법 결정 | `df.describe()`, skewness, Q-Q plot, Shapiro-Wilk |
| Q2 | 오염된 데이터 정리 → 집계·파생변수 생성의 기반 확보 | `duplicated()`, `to_datetime()`, `value_counts()` |
| Q3 | 결측 패턴 파악 → 처리 전략(제거 vs 대체) 판단 근거 | `isna().mean()`, 히트맵 |
| Q4 | 처리 방법에 따른 분포 변화 비교 → 최적 전략 선택 | `dropna()`, `groupby().median()`, Mann-Whitney U, Cohen's d |
| Q5 | 극단값이 통계량을 왜곡하는지 확인 → 모델 안정성 확보 | 도메인 규칙, IQR, 박스플롯 |
| Q6 | 제거 vs 절단 트레이드오프 비교 → 정보 손실 최소화 | `clip()`, remove, 가설 검정 |
| Q7 | 원본 변수로 안 보이는 패턴 발굴 → 설명력 향상 | `pd.cut()`, 시간대/요일/계절 파생 |
| Q8 | 비즈니스 질문에 데이터로 답하기 → 운영 의사결정 | 시간대별 집계, 전/후 오버레이 |
| Q9 | 변수 간 관계 파악 + 다중공선성 확인 → 예측 변수 선정 | 상관 히트맵, 산점도, p-value, VIF |
| Q10 | 분석 결과를 실행 가능한 제안으로 전환 → 스토리텔링 | 사실-근거-제안 구조 |
| 심화 | 변수가 많을 때 차원 축소 → 핵심 축 발견 | PCA, 설명 분산 비율 |
| 심화 | 어떤 변수가 수요를 가장 잘 나누는지 → 분기 기준 탐색 | DecisionTree, feature_importances_ |

## 4) 과제 문항 (총 10문항 + 심화 2문항)

### 1. 데이터 스키마 점검 + 분포 진단
> **목적: 데이터 상태를 파악하고, 분포를 확인하여 후속 분석 방법을 결정한다**
- 해야 할 일: 변수 타입, 행/열 수, 기초 통계량 확인 + 타깃 변수의 분포 특성 파악
- 왜 필요한가: 전처리 전 상태를 기준선으로 잡고, 분포 형태에 따라 후속 검정 방법이 달라지기 때문
- 필수 결과: `데이터 프로파일 표` 1개 + `타깃 히스토그램 & Q-Q plot` + `skewness/kurtosis 보고`
- 정규성 검정(Shapiro-Wilk)을 수행하고, 결과에 따라 Q4/Q6에서 모수/비모수 검정을 선택한다

### 2. 중복 및 타입 오류 점검
> **목적: 오염된 데이터를 정리하여 집계·파생변수 생성의 기반을 확보한다**
- 해야 할 일: 중복 행, 비정상 범주, 날짜/시간 파싱 오류 점검
- 왜 필요한가: 중복과 형식 오류는 집계 결과를 직접 망가뜨리며, 날짜 파싱이 실패하면 후속 시계열 분석과 파생 변수 생성이 불가능하기 때문
- 필수 결과: `문제 건수 표` + `수정 전/후 레코드 예시`
- **주의**: 이 단계를 먼저 처리해야 Q3 이후의 결측치/이상치 분석이 올바르게 작동합니다.

### 3. 결측치 진단
> **목적: 결측 패턴을 파악하여 제거 vs 대체 전략의 판단 근거를 마련한다**
- 해야 할 일: 변수별 결측 비율 계산, 결측 패턴 시각화
- 왜 필요한가: 결측이 랜덤인지 특정 조건에 몰려있는지 확인하기 위해
- 필수 결과: `결측 비율 막대그래프` + `결측 패턴 히트맵`

### 4. 결측치 처리 전략 A/B 비교
> **목적: 처리 방법에 따른 분포 변화를 비교하여 최적 전략을 선택한다**
- 해야 할 일: 아래 2개 전략을 각각 적용하고 결과 비교
1. 단순 제거(`drop`)
2. 그룹 기반 대체(예: 시간대/요일별 중앙값)
- 왜 필요한가: 처리 방식에 따라 표본 수와 분포가 달라지기 때문
- 필수 결과: `처리 전/후 분포 그래프` + `행 수 변화 표` + `가설 검정 결과`
- **가설 검정**: 처리 전/후 분포 차이가 통계적으로 유의한지 검정한다 (Q1 정규성 결과에 따라 t-test 또는 Mann-Whitney U 선택)
- **효과 크기**: Cohen's d를 보고하여 차이의 실질적 크기를 평가한다 (|d|<0.2 무시, <0.5 소, <0.8 중, ≥0.8 대)

### 5. 이상치 탐지
> **목적: 극단값이 통계량을 왜곡하는지 확인하여 모델 안정성을 확보한다**
- 해야 할 일: 아래 두 단계로 이상치 후보 식별
  1. **도메인 규칙 확인**: 물리적으로 불가능한 값이 있는가? (예: 대여 수 < 0, 강수량 < 0)
  2. **통계 기준 적용**: IQR 또는 Z-score로 극단값 식별
- 왜 필요한가: 극단값이 평균/분산/상관을 왜곡할 수 있기 때문
- 필수 결과: `박스플롯` + `산점도` (이상치 마킹) + `도메인 규칙 위반 건수 표`

### 6. 이상치 처리 전략 A/B 비교
> **목적: 제거 vs 절단의 트레이드오프를 비교하여 정보 손실을 최소화한다**
- 해야 할 일: 아래 2개 전략을 각각 적용하고 결과 비교
1. 이상치 제거
2. 윈저라이징(상하위 임계값으로 절단)
- 왜 필요한가: 제거와 절단은 보존 정보량과 왜곡 감소에서 트레이드오프가 다름
- 필수 결과: `전/후 박스플롯` + `요약통계 변화 표` + `가설 검정 결과`
- **가설 검정**: Q4와 동일하게 처리 전/후 차이의 유의성과 효과 크기를 보고한다

### 7. 파생 변수 생성
> **목적: 원본 변수로 안 보이는 패턴을 발굴하여 설명력을 높인다**
- 해야 할 일: 시간대 구간, 주말/평일, 계절 등 파생 변수 생성
- 왜 필요한가: 원본 변수만으로는 패턴이 숨겨질 수 있기 때문
- 필수 결과: `파생 변수 정의 표` + `구간별 수요 그래프`

### 8. 핵심 질문 1 분석
> **목적: 비즈니스 질문에 데이터로 답하여 운영 의사결정을 지원한다**
- 질문: "수요 피크 시간은 언제인가?"
- 해야 할 일: 처리 전/후 각각 피크 시간 비교
- 필수 결과: `시간대별 라인차트` (전/후 오버레이)

### 9. 핵심 질문 2 분석
> **목적: 변수 간 관계를 파악하고 다중공선성을 확인하여 예측에 쓸 변수를 선정한다**
- 질문: "날씨(기온/강수/습도)는 수요와 어떤 관계가 있는가?"
- 해야 할 일: 변수 간 관계를 시각화하고 처리 전/후 차이 설명
- 필수 결과: `상관 히트맵` + `기상 변수 vs 수요 산점도` + `상관 유의성 검정(p-value)`
- **유의성 표기**: 각 상관계수에 p-value를 보고한다 (*** p<0.001, ** p<0.01, * p<0.05, ns 비유의)
- **다중공선성 체크**: 기상 변수끼리 상관이 높은 쌍이 있는지 확인한다 (예: Temperature와 DewPoint). 상관이 0.8 이상인 쌍이 있으면 모델링 시 주의가 필요하다는 점을 언급한다

### 10. 결론 및 권고안
> **목적: 분석 결과를 실행 가능한 제안으로 전환한다 (데이터 → 의사결정)**
- 해야 할 일: 최종 인사이트 3개, 운영 제안 1개, 분석 한계 2개 제시
- 왜 필요한가: 분석 결과를 의사결정 문장으로 바꾸는 훈련
- 필수 결과: `요약 슬라이드 스타일 페이지` 1장

### 심화 A. 차원 축소로 핵심 축 발견하기 (PCA)
> **목적: 변수가 많을 때 차원을 축소하여 데이터의 핵심 구조를 파악한다**
- 해야 할 일: 기상 변수(Temperature, Humidity, WindSpeed, Visibility, DewPoint, SolarRadiation)에 PCA를 적용한다
- 왜 필요한가: 기상 변수끼리 상관이 높으면(다중공선성) 개별 변수보다 주성분이 더 안정적인 설명 변수가 될 수 있다
- 필수 결과:
  - 설명 분산 비율(explained variance ratio) 막대그래프
  - 누적 설명 분산이 80%를 넘는 주성분 수 보고
  - PC1-PC2 산점도 (수요 레벨을 색으로 구분)
  - 각 주성분의 로딩(loading)을 해석하여 "PC1 = 무엇을 의미하는가" 서술
- **사전 조건**: PCA 전에 반드시 표준화(StandardScaler)를 수행한다. 스케일이 다른 변수에 PCA를 그냥 적용하면 분산이 큰 변수가 지배한다

### 심화 B. 트리 기반 변수 중요도 탐색
> **목적: 어떤 변수가 수요를 가장 잘 나누는지 분기 기준을 탐색한다**
- 해야 할 일: 전처리 완료된 데이터에 DecisionTreeRegressor를 적용하고 변수 중요도를 확인한다
- 왜 필요한가: 상관 분석은 선형 관계만 포착하지만, 트리는 비선형 분기를 잡아낸다. 두 결과를 비교하면 변수의 역할을 더 입체적으로 이해할 수 있다
- 필수 결과:
  - `feature_importances_` 수평 막대그래프
  - 상관 분석(Q9) 순위와 트리 중요도 순위 비교 표
  - 순위가 다른 변수가 있다면 "왜 다른가?" 해석 (예: Hour는 상관이 낮지만 트리에서 최상위 — 비선형 패턴이기 때문)
- **주의**: 이 단계는 예측 모델 구축이 아닌 EDA 목적이므로 정확도 평가는 불필요. 분기 기준을 통해 변수의 비선형 영향력을 파악하는 데 집중한다
- **깊이 제한 권장**: `max_depth=4` 정도로 제한하여 해석 가능한 트리를 만든다
