### 1. 경제학적 감을 AI로 공부하는 방법

핵심 원칙: AI에게 "알려줘"가 아니라 "내가 판단 -> AI가 검증"

#### 공부할 프레임워크 (우선순위)
[필수]
- 거시 기본등식: Y=C+I+G+NX, Y=AF(K,L), MV=PY
- 금리 구조: 명목금리=실질금리+기대인플레, 테일러 룰
- 환율 결정: 금리차, 경상수지, 자본흐름
- 리스크 프레임: VIX, 신용스프레드, TED스프레드

[다음]
- IS-LM / AS-AD, 필립스 커브, 먼델-플레밍, CAPM/팩터모델

[심화]
- 통화정책 전달경로, 금융불안정성 (민스키)

#### 3단계 능동 학습법 (1회 40분)
1. 개념 획득 (15분): AI에게 개념 설명 요청, 수식 포함
2. 현실 적용 (15분): 지금 한국/미국 상황에 적용, 내가 먼저 판단 -> AI 검증
3. 연결 확장 (10분): 이 개념이 다른 변수에 미치는 경로 추적

#### "오늘의 1문장 판단" 루틴
- 뉴스 하나 -> 내가 리스크 팩터 판단 -> AI에게 반론 요청
- 선배: "여러 아이디어를 받고 검증하면서 수렴시키기" (aifi.txt 164행)

### 3. 경로추적 + 예측모형 시스템 설계

#### 디렉토리 구조
aieco/
  study/frameworks/    경제 프레임워크별 정리
  tracker/daily/       일일 뉴스-판단 기록 (JSON)
  tracker/paths.db     SQLite: 뉴스-팩터-영향 매핑
  model/baseline.json  현재 베이스라인 전망
  model/history/       월별 스냅샷
  model/review/        복기 기록
  agents/              자동화 에이전트 (나중)

#### DB 테이블
- events: 뉴스 이벤트 + 내 판단
- risk_factors: 리스크 팩터 분류 (macro/financial/geopolitical/sector)
- impact_paths: 이벤트->팩터->시장영향 경로 매핑 + 사후 검증
- baseline: 변수별 예측 + 복기

#### 발전 로드맵
[수동] 나 -> 뉴스 -> 판단 기록 -> JSON/SQLite
[반자동] 뉴스 수집 에이전트 -> 내가 판단 -> AI 반론 -> DB 저장
[자동] 뉴스 수집 -> 자동 팩터 분류 -> 경로 제안 -> 승인/수정 -> 월간 리포트

#### 핵심 원칙 (선배)
- "사람이 보기 편한 건 비효율적. CLI로 되게" (97행)
- 대시보드는 나중, 지금은 JSON + SQLite + CLI
- "5년 모으면 DB -> LLM 훈련 -> 나만의 것" (179-180행)
