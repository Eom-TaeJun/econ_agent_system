# AI DATA ANALYSIS: SESSION 4 REVISED
## 주제: 모델 평가와 실전의 스위트 스팟

## 슬라이드 0: 강의 개요
- 학회: Parrot
- 강의 주제: 성능 평가 지표와 모델 검증
- 강의자: 엄태준

## 슬라이드 1: 성능 평가의 철학: "잘 만들었는가?"
- 상황: 모델 생성 후 실제 비즈니스 현장 투입 전의 결정적 검증 단계
- 목적: 모델의 신뢰성을 숫자로 증명하고 잠재적 리스크를 정량화
- 핵심: 단순히 오차를 줄이는 것을 넘어 비즈니스 가치에 부합하는지 판단

## 슬라이드 2: 정확도 (Accuracy)의 함정
- 현상: 99%의 데이터가 정상인 경우, 무조건 정상이라 해도 정확도 99% 달성
- 문제: 우리가 진짜 찾고자 하는 1%의 이상치 (Signal)를 놓칠 위험
- 결론: 데이터 불균형 (Imbalance) 환경에서 정확도는 가장 위험한 지표

## 슬라이드 3: 판단의 지도: 오차 행렬 (Confusion Matrix)
- 구성: 실제 정답과 모델 예측의 조합으로 만든 2x2 상태 매트릭스
- 4요소: 정탐지 (TP), 미탐지 (FN), 오탐지 (FP), 정상탐지 (TN)
- 가치: 모델이 어떤 성격의 실수를 저지르고 있는지 물리적으로 파악 가능

## 슬라이드 4: 정밀도 (Precision): 모델의 확신성
- 정의: 모델이 긍정 (Positive)이라 예측한 것 중 실제 긍정인 비율
- 의미: 모델이 내뱉은 확신 중 진짜 정답이 얼마나 섞여 있는가?
- 비유: 양치기 소년이 늑대가 나타났다고 외칠 때의 신뢰도

## 슬라이드 5: 재현율 (Recall): 신호 검출 능력
- 정의: 실제 긍정인 데이터들 중 모델이 긍정이라 맞춘 비율
- 의미: 우리가 반드시 찾아야 할 대상 중 얼마나 놓치지 않고 포착했는가?
- 비유: 수사관이 범죄 현장에서 유의미한 증거를 수집해내는 검거율

## 슬라이드 6: 정밀도 vs 재현율 트레이드오프
- 역설: 한 지표를 억지로 높이려 하면 다른 지표는 반드시 낮아지는 관계
- 원인: 모델의 판단 기준 (임계값)을 엄격하게 하느냐 느슨하게 하느냐의 차이
- 목표: 두 지표 사이에서 비즈니스 목적에 따른 최적의 균형점 탐색

## 슬라이드 7: 조화로운 지표: F1 스코어
- 정의: 정밀도와 재현율의 조화 평균 (Harmonic Mean)
- 가치: 어느 한 지표로 치우치지 않는 모델의 종합적인 분류 성능 측정
- Why: 낮은 값에 더 민감하게 반응하여 불균형 데이터의 성능을 잘 투영

## 슬라이드 8: 비즈니스 스위트 스팟 1: 암 진단 모델
- 우선순위: 재현율 (Recall)의 극대화가 생존과 직결된 핵심 과제
- 리스크: 실제 환자를 정상으로 오판 (미탐지)하는 행위는 생명에 치명적
- 전략: 판단 임계값을 대폭 낮추어 조금이라도 의심되면 정밀 검사 권고

## 슬라이드 9: 비즈니스 스위트 스팟 2: 스팸 메일 필터
- 우선순위: 정밀도 (Precision)의 확보가 사용자 경험의 핵심
- 리스크: 중요한 업무 메일을 스팸으로 오판 (오탐지)하여 차단하는 것은 치명적
- 전략: 판단 임계값을 높여 아주 확실한 경우에만 스팸함으로 분류

## 슬라이드 10: 판단의 기준선: 임계값 (Threshold) 조정
- 원리: 모델이 출력하는 0~1 사이 확률값의 최종 판정 절단 지점 설정
- 활용: 임계값을 이동시키며 정밀도와 재현율의 비중을 유동적으로 조절
- 가치: 수학적 모델은 동일해도 임계값 하나로 비즈니스 성격 변경 가능

## 슬라이드 11: 모든 기준에서의 성능: AUC-ROC
- ROC 곡선: 임계값을 변화시킬 때의 정탐지율과 오탐지율의 궤적 시각화
- AUC (Area Under Curve): 곡선 아래의 면적 (1에 가까울수록 분류 잠재력 높음)
- 장점: 특정 임계값 설정과 무관하게 모델 자체의 순수한 변별력 평가

## 슬라이드 12: 회귀 모델의 지표: MSE 및 RMSE
- MSE (Mean Squared Error): 실제값과 예측값 차이의 제곱 평균
- RMSE (Root MSE): MSE에 루트를 씌워 실제 데이터와 단위를 맞춘 지표
- 특징: 큰 오차에 대해 제곱의 패널티를 부여하여 이상치 관리에 민감

## 슬라이드 13: 직관적인 평가: MAE (Mean Absolute Error)
- 정의: 오차의 절대값에 대한 산술 평균
- 장점: 에러의 물리적 크기가 실제 단위와 정확히 일치하여 해석이 용이
- 비교: 제곱을 하지 않아 이상치에 상대적으로 둔감하며 일반적 성능 파악에 유리

## 슬라이드 14: 모델의 설명력 지수: R-Square
- 의미: 모델이 전체 데이터의 변동성 (Variance)을 얼마나 설명하고 있는가?
- 범위: 0에서 1 사이의 값을 가지며 1에 가까울수록 설명력이 높음을 의미
- 주의: 데이터의 특성에 따라 절대적 수치보다 상대적 개선 추이가 더 중요

## 슬라이드 15: 실전 검증의 정석: 교차 검증 (Cross-Validation)
- 문제: 특정 테스트 셋에만 우연히 잘 맞는 운 (Luck)의 요소를 철저히 배제
- 방식: 전체 데이터를 N개의 조각으로 나눠 번갈아가며 학습과 검증 반복
- 가치: 모델이 실제 운영 환경에서 보여줄 예상 성능을 가장 안정적으로 추정

## 슬라이드 16: 결론: 숫자를 넘어 가치로 평가하라
- 철학: 수학적 최적점과 비즈니스적 최적점은 상황에 따라 다를 수 있음
- 분석: 오탐 비용과 미탐 비용을 실제 금액으로 환산하여 최종 의사결정
- 메시지: 지표의 노예가 되지 말고 지표를 활용해 가치를 입증하는 주인이 될 것
