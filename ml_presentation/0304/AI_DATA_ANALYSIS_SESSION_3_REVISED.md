## 주제: 부스팅의 정점과 하이퍼파라미터

## 슬라이드 0: 강의 개요
- 학회: Parrot
- 강의 주제: XGBoost와 부스팅 최적화
- 강의자: 엄태준

## 슬라이드 1: 부스팅의 진화: Gradient Boosting (GBM)
- 원리: 손실 함수를 최소화하는 방향으로 모델을 업데이트하는 기법
- 혁신: 경사 하강법 (Gradient Descent)의 원리를 부스팅에 결합
- Why: 잔차 (Residual)를 직접 계산하는 대신 손실 함수의 기울기 활용

## 슬라이드 2: 잔차 학습의 수학적 의미
- 목표: 현재 모델 f(x)가 놓치고 있는 정보인 y - f(x)를 학습
- 과정: 매 단계마다 잔차를 줄여나가는 새로운 나무 (Additivity) 추가
- 결과: 학습이 진행됨에 따라 목적 함수가 전역 최적점에 도달

## 슬라이드 3: 현대 ML의 주역: XGBoost의 등장
- 배경: 기존 GBM의 느린 연산 속도와 과적합 취약성을 해결하기 위해 탄생
- 위상: 데이터 사이언스 대회 우승자들의 필수 도구이자 정형 데이터의 왕좌
- 가치: 압도적 성능과 속도, 그리고 과적합 방지 로직의 집약체

## 슬라이드 4: XGBoost의 핵심: 테일러 전개 (Taylor Expansion)
- 수식: f(x) 약 f(a) + f'(a)(x-a) + 0.5 f''(a)(x-a)^2
- Why: 2차 미분항 (Hessian)을 활용하여 목적 함수를 정밀하게 근사
- 효과: 1차 미분만 쓰던 기존 방식보다 월등히 빠르고 정확한 수렴 보장

## 슬라이드 5: 목적 함수의 재구성: 자체 정규화 (Regularization)
- 특징: 손실 함수에 나무의 복잡도 (가중치 제곱합 등)를 패널티로 추가
- 효과: 학습 과정에서 모델의 비대화를 스스로 억제하여 일반화 성능 강화
- Why: 모델이 데이터에 과하게 적응하는 것을 수식 수준에서 원천 차단

## 슬라이드 6: 하드웨어 최적화: 병렬 처리 기술
- 혁신: 데이터 정렬 및 분할 지점 탐색 과정의 병렬화 (Parallelism)
- 기술: 캐시 최적화 (Cache-aware) 및 메모리 블록 관리 기법 적용
- 가치: 대규모 데이터셋에서도 GPU/CPU 자원을 극한으로 활용하여 시간 단축

## 슬라이드 7: 결측치 처리와 희소성 대응
- 지능: 학습 시 결측치가 갈 최적의 방향 (Default Direction)을 스스로 결정
- 편의: 별도의 결측치 대체 (Imputation) 과정 없이도 견고한 모델 유지
- 효과: 불완전한 실제 필드 데이터에 대응하는 강력한 회복력 확보

## 슬라이드 8: 하이퍼파라미터: 모델의 정밀 조절자
- 정의: 학습 시작 전 사람이 직접 설정하여 모델의 동작 방식을 제어하는 변수
- 중요성: 동일한 알고리즘이라도 설정값에 따라 전혀 다른 성능 도출
- 자세: 도구를 지배하기 위해 파라미터 간의 상호작용을 이해하는 것이 필수

## 슬라이드 9: 핵심 파라미터 1: 학습률 (Learning Rate)
- 역할: 각 단계 모델의 기여도를 얼마나 반영할지 결정하는 감쇄 계수
- 전략: 낮을수록 꼼꼼히 학습하지만 더 많은 나무와 긴 시간이 필요
- 조언: 낮은 학습률과 충분한 반복 횟수를 조합하여 최적의 성능 도출

## 슬라이드 10: 핵심 파라미터 2: 나무의 깊이 (Max Depth)
- 역할: 개별 의사결정 나무가 가질 수 있는 최대 층수 제한
- 영향: 깊을수록 복잡한 상호작용을 잡지만 과적합 위험이 지수적 상승
- 가이드: 데이터 복잡도에 따라 보통 3에서 10 사이에서 최적점 탐색

## 슬라이드 11: 핵심 파라미터 3: 서브샘플링 (Sub-sampling)
- 행 샘플링: 각 나무 학습 시 전체 데이터의 일부만 무작위로 사용
- 열 샘플링: 분할 시 변수의 일부만 무작위로 선택 (Feature Sampling)
- 효과: 모델 간의 상관관계를 낮추어 앙상블의 다양성과 일반화 능력 극대화

## 슬라이드 12: 최적 조합 탐색: 그리드 서치 (Grid Search)
- 방식: 사람이 지정한 모든 파라미터 조합을 전수 조사하여 비교
- 단점: 탐색 범위가 넓어질수록 연산량이 기하급수적으로 증가하는 부하 발생
- 특징: 가장 확실한 방법이지만 시간과 자원 소모가 가장 큰 최적화 방식

## 슬라이드 13: 효율적 탐색: 랜덤 서치 (Random Search)
- 방식: 정해진 확률 분포 내에서 무작위로 조합을 선택하여 테스트
- 장점: 그리드 서치보다 훨씬 적은 시도로 유사하거나 더 나은 성능 확보
- Why: 중요도가 낮은 파라미터에 자원을 낭비하지 않고 핵심 영역에 집중

## 슬라이드 14: 차세대 엔진: LightGBM의 혁신
- 특징: 수평적 성장이 아닌 리프 중심 (Leaf-wise) 수직 성장 방식 채택
- 혁신: 대용량 데이터에서 메모리 사용량과 학습 시간을 획기적으로 절감
- 기술: 기울기가 큰 샘플 위주로 학습하는 GOSS 기술 등 최신 기법 적용

## 슬라이드 15: 도구 선택 가이드: XGBoost vs LightGBM
- XGBoost: 중간 규모 데이터에서의 검증된 안정성과 정밀한 제어
- LightGBM: 대규모 데이터셋에서의 압도적인 속도와 효율적 자원 사용
- 결론: 데이터의 크기와 분석 환경의 자원에 따른 유연한 도구 전환

## 슬라이드 16: 하이퍼파라미터 튜닝의 본질적 철학
- 경계: 파라미터 조정만으로는 데이터 자체의 정보 한계를 넘을 수 없음
- 우선순위: 고도화된 특징 공학 (Feature Engineering)이 튜닝보다 항상 우선됨
- 메시지: 튜닝은 잘 정제된 데이터의 가치를 마지막 1%까지 쥐어짜는 과정

## 슬라이드 17: 요약: 부스팅을 지배하는 법
- 원리: 잔차를 정복해나가는 정교한 수학적 최적화의 연속
- 기술: 테일러 근사와 하드웨어 병렬 처리의 결합으로 완성된 성능
- 태도: 파라미터의 반응을 살피며 데이터의 본질을 찾아가는 실험적 접근
