# AI DATA ANALYSIS: SESSION 2 REVISED
## 주제: 트리 모델과 앙상블의 지혜

## 슬라이드 0: 강의 개요
- 학회: Parrot
- 강의 주제: 트리 모델과 앙상블의 진화
- 강의자: 엄태준

## 슬라이드 1: 의사결정 나무의 직관
- 원리: 스무고개 방식의 재귀적 데이터 분할 프로세스
- 특징: 복잡한 비선형 현상을 단순한 이진 질문들로 해체
- 목표: 집단의 불순도를 최소화하는 최적의 경계면 탐색

## 슬라이드 2: 분할의 기준: 지니 계수와 엔트로피
- 지니 계수 (Gini Impurity): 집단 내 잘못 분류될 확률을 수치화
- 엔트로피 (Entropy): 정보 이론 관점의 무질서도 측정 지표
- Why: 어떤 질문이 정보 획득 (Information Gain)을 극대화하는지 판단

## 슬라이드 3: 나무 모델의 강점: 투명성과 해석력
- 특징: 판단의 근거를 트리 도식으로 직접 확인 가능
- 가치: 로직의 흐름이 명확하여 비즈니스 설득 및 규제 대응에 유리
- 차별점: 블랙박스가 아닌 화이트박스 (White Box) 모델의 전형

## 슬라이드 4: 단일 나무의 치명적 한계: 불안정성
- 문제: 데이터의 미세한 변화에도 트리 구조가 급변함
- 원인: 훈련 데이터의 국소적 특징에 너무 깊게 파고드는 경향
- 결과: 일반화 성능이 낮고 예측 결과의 분산이 매우 높음

## 슬라이드 5: 이론적 배경: 편향 (Bias)과 분산 (Variance)
- 편향: 모델의 단순함으로 인해 데이터의 본질적 관계를 놓치는 오차
- 분산: 데이터 변화에 모델이 민감하게 반응하여 발생하는 오차
- 핵심: 모델의 총 오차는 이 두 요소의 합으로 구성됨

## 슬라이드 6: 바이어스-베리언스 트레이드오프의 역설
- 상충 관계: 편향을 줄이면 분산이 늘고, 분산을 줄이면 편향이 증가
- 목표: 두 오차의 합이 최소화되는 최적의 모델 복잡도 탐색
- 해결: 단일 모델의 한계를 극복하기 위한 앙상블 (Ensemble)의 필요성

## 슬라이드 7: 앙상블의 철학: 집단 지성의 수식화
- 개념: 하나의 천재보다 수만 명의 평범한 모델들의 결합이 강력함
- 방식: 여러 개의 약한 학습기 (Weak Learner)를 하나로 묶어 성능 극대화
- 전략: 개별 모델의 고유한 오류를 서로 상쇄하며 견고함 (Robustness) 유지

## 슬라이드 8: 앙상블의 두 줄기: 배깅과 부스팅
- 구분: 모델을 병렬로 결합하는가, 순차로 결합하는가에 따른 분류
- 배깅 (Bagging): 분산을 줄여 모델의 안정성을 높이는 데 주력
- 부스팅 (Boosting): 편향을 줄여 모델의 정확도를 높이는 데 주력

## 슬라이드 9: 방법론 1: 배깅 (Bagging)의 원리
- 핵심: 부트스트랩 (Bootstrap) 샘플링을 통한 데이터 다양성 확보
- 과정: 중복을 허용한 무작위 샘플 추출 및 독립적 병렬 학습
- 효과: 여러 데이터 단면을 학습한 모델들의 결과를 평균화 (Aggregating)

## 슬라이드 10: 배깅의 정점: 랜덤 포레스트
- 혁신: 데이터뿐만 아니라 변수 (Feature)도 무작위로 선택하여 학습
- 효과: 나무들 간의 상관관계를 낮추어 독립성 (De-correlation) 극대화
- 가치: 대수의 법칙에 기반하여 분산을 획기적으로 낮춘 안정적 도구

## 슬라이드 11: 방법론 2: 부스팅 (Boosting)의 원리
- 핵심: 이전 모델의 실수를 다음 모델이 이어받아 집중적으로 교정
- 과정: 오답 데이터에 더 큰 가중치를 부여하여 순차적 (Sequential) 학습
- 목표: 모델이 풀기 어려워하는 데이터 영역을 정복하여 성능 향상

## 슬라이드 12: 부스팅의 순차 학습 메커니즘
- 방식: 이전 단계의 오차 (Residual)를 새로운 타겟으로 설정하여 학습
- 가중치 조정: 틀린 샘플은 강조하고 맞춘 샘플의 비중은 축소
- 진화: 반복을 거듭할수록 전체 모델의 표현력이 비약적으로 향상

## 슬라이드 13: 부스팅의 마법: 편향 제거
- 이유: 단순한 모델들을 누적하여 복잡한 데이터 경계를 정밀하게 묘사
- 효과: 앙상블을 거듭할수록 예측값이 실제값에 극도로 수렴
- Why: 학습의 초점이 항상 해결되지 않은 잔차에 맞춰져 있기 때문

## 슬라이드 14: 비교 분석: 배깅 vs 부스팅
- 속도: 병렬 처리가 가능한 배깅이 순차 학습인 부스팅보다 유리
- 성능: 하이퍼파라미터 최적화 시 부스팅이 일반적으로 높은 정확도 달성
- 안정성: 배깅은 과적합에 매우 강하며, 부스팅은 과적합 위험 관리 필수

## 슬라이드 15: 피처 임포턴스: 앙상블의 판단 근거
- 의미: 수만 번의 데이터 분할 중 특정 변수가 기여한 총량 측정
- 지표: 불순도를 낮춘 정도나 예측 정확도 기여도를 전역적으로 집계
- 한계: 변수 간 다중공선성이 높을 경우 특정 변수의 영향력이 왜곡될 위험

## 슬라이드 16: 결론: 도구의 전략적 선택
- 성격: 데이터의 노이즈가 많으면 배깅, 정확도가 우선이면 부스팅 선택
- 학습: 각 기법의 수학적 원리와 트레이드오프 관계를 명확히 인지
- 메시지: 문제의 성격에 맞춰 최적의 앙상블 무기를 골라 쓰는 통찰력 배양
