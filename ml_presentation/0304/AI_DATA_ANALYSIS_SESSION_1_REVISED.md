## 주제: 예측의 철학과 손실 함수의 경제학

## 슬라이드 0: 강의 개요
- 학회: Parrot
- 강의 주제: 머신러닝의 철학과 손실 함수
- 강의자: 엄태준

## 슬라이드 1: 상관관계 ≠ 인과관계
- 상관관계 (Correlation): 두 변수가 함께 움직이는 통계적 경향성
- 인과관계 (Causality): 한 변수의 변화가 결과의 직접적 원인이 되는 관계
- 식별 문제: 기전(Mechanism) 없는 상관성을 인과로 오판하는 위험성 경계

## 슬라이드 2: 데이터 분석의 과학적 프로세스
- 단계: 현상 관찰 → 가설 설정 → 실험 설계 → 데이터 분석 → 인과 규명
- 핵심: 상관성을 논리적·수학적 과정을 통해 인과성으로 좁혀가는 여정
- 가치: 데이터 표면의 노이즈를 걷어내고 본질적 패턴을 발견하는 과정

## 슬라이드 3: 실험적 검증의 당위성: A/B Test
- 원리: 실험군과 대조군의 무작위 배정을 통한 처리 효과(Treatment Effect) 산출
- 특징: 변수 간의 외생성 확보를 통해 인과관계를 통계적으로 증명
- Why: 기전을 완벽히 몰라도 엄밀한 실험적 증거가 반복되면 인과로 인정

## 슬라이드 4: 분석의 궁극적 지향점: 예측과 설득
- 예측 (Prediction): 보이지 않는 미래 데이터(y_T+1)를 수치로 가장 정확하게 타격
- 설득 (Persuasion): 데이터 기반의 논리적 근거(Evidence)로 의사결정권자를 움직임
- 분석의 미학: 단순한 숫자 나열을 넘어 비즈니스 행동으로 바꾸는 트리거

## 슬라이드 5: 기술의 역사: 고전 통계에서 에이전틱 AI까지
- 과거 (Statistics): 엄밀한 수식 증명과 인과 규명 중심의 고전 통계학
- 현재 (Machine Learning): 압도적 연산량 기반의 예측 성능 중심 머신러닝
- 미래 (Agentic AI): 학습된 모델을 바탕으로 스스로 판단하고 행동하는 시스템

## 슬라이드 6: 고전 통계학의 근본 철학: 모집단과 추론
- 철학: 모집단(Population)이 데이터를 생성하는 근본적인 규칙(DGP) 식별에 집착
- 방법: 샘플 데이터를 통해 모집단의 모수(Beta)를 추정하고 가설 검정 수행
- 가치: 모델의 수식적 신뢰성(Reliability)과 추론의 엄밀함을 최우선으로 설정

## 슬라이드 7: 선형회귀: 수식적 정의와 인과적 해석
- 수식: y = Xb + e (종속변수 = 독립변수와 가중치의 결합 + 오차항)
- 해석: 독립변수의 단위 변화가 종속변수에 미치는 한계 반응(Marginal Effect) 측정
- Why: 가장 강력한 해석력(Interpretability)을 제공하며 모든 현대 ML의 기초가 됨

## 슬라이드 8: 통계적 한계 (1): 다중공선성
- 현상: 독립변수 간 강한 선형 상관관계가 존재하여 개별 영향력 식별 불가
- 수식 오류: 행렬(X'X)의 역행렬 존재 조건 위반으로 인한 회귀 계수의 분산 폭주
- 결과: 어떤 변수가 진짜 인과적 기여를 하는지 수치적으로 판단 불가능한 상태

## 슬라이드 9: 통계적 한계 (2): 차원의 저주
- 현상: 변수(차원)가 증가함에 따라 데이터 밀도가 지수적으로 감소하는 현상
- 영향: 샘플 간 거리가 멀어지는 데이터 희소성(Sparsity) 발생으로 패턴 학습 무력화
- 한계: 고차원 대용량 데이터 환경에서 고전적 추정 방식의 성능이 급감하는 이유

## 슬라이드 10: 시대적 전환: 머신러닝의 탄생 배경
- 데이터: 인터넷 및 센서 보급에 따른 비정형·고차원 데이터의 폭발적 증가
- 컴퓨팅: GPU 기반 대규모 병렬 연산 및 분산 처리 기술의 비약적 발전
- 필요성: 사람이 직접 규칙을 짜는 방식의 한계를 넘는 데이터 기반 자동화 요구

## 슬라이드 11: 머신러닝 패러다임: 예측 정확도의 극대화
- 철학: "내부 기전을 완벽히 설명하지 못해도 좋으니, 정확하게 적중하라"
- 전략: 복잡한 비선형 구조와 연산 부하를 감수하며 예측 오차(Loss)를 최소화
- 전환: 인과 구조의 규명(Inference)에서 결과의 적중(Prediction)으로의 이동

## 슬라이드 12: 손실 함수(Loss Function)의 수학적 정의
- 정의: 모델의 예측값(f)과 실제값(y)의 차이를 수치화한 비용 함수 L(f, y)
- 목적: 모델 학습 시 최소화해야 할 목적 함수(Objective Function)의 핵심 지표
- 역할: 어떤 종류의 오차에 더 큰 패널티를 줄 것인지 결정하는 경제적 기준

## 슬라이드 13: 손실 함수의 공통 성질: 비음수성 및 단조성
- 비음수성: 모든 오차에 대한 비용은 0보다 크거나 같음 (L >= 0)
- 단조성: 예측값이 실제값에서 멀어질수록 손실의 크기는 줄어들지 않고 증가
- Why: 손실의 최소값은 예측이 완벽할 때(f=y) 0이 되는 지점으로 설정

## 슬라이드 14: 대칭적 손실: 제곱 오차(MSE)와 절대 오차(MAE)
- 제곱 오차 (Quadratic Loss): 오차의 제곱에 비례하여 큰 오차에 매우 강한 패널티 부여
- 절대 오차 (Absolute Loss): 오차의 크기에 선형적으로 비례하며 이상치에 상대적으로 견고
- 특징: 예측값의 과대평가와 과소평가에 동일한 비용을 부과하는 대칭 구조

## 슬라이드 15: 비대칭적 손실: 예측 방향에 따른 비용 차이
- 현상: 현실 비즈니스에서는 오차의 방향에 따라 발생하는 기회비용이 서로 다름
- 예시: 재고 관리 시 과소예측(품절 비용)과 과대예측(재고 유지 비용)의 불균형
- Why: 상황에 맞는 최적의 비대칭 손실 함수를 선택하는 것이 모델러의 역량

## 슬라이드 16: 최적 예측의 원리: 기대 손실의 최소화
- 원리: 단순히 오차를 줄이는 것이 아니라 기대 손실 E[L(f, Y)]을 최소화하는 것
- 과정: 데이터의 조건부 분포를 고려하여 평균적으로 가장 비용이 적은 예측치 산출
- 가치: 수학적 최적화가 비즈니스적 이익 극대화로 연결되는 핵심 기전

## 슬라이드 17: 과적합(Overfitting): 정확도의 독배
- 현상: 훈련 데이터 오차는 0에 수렴하나 검증 데이터 오차는 급격히 상승
- 원인: 데이터 내 유의미한 신호(Signal)가 아닌 무작위 노이즈(Noise)까지 학습
- 결론: 일반화(Generalization) 능력이 없는 모델은 실전에서 가치를 상실함

## 슬라이드 18: 바이어스-베리언스 트레이드오프의 역설
- 편향 (Bias): 모델의 단순함으로 인해 데이터의 본질적 관계를 놓치는 오차
- 분산 (Variance): 모델의 복잡함으로 인해 데이터의 작은 변동에 민감하게 반응하는 오차
- 역설: 하나를 줄이려 하면 다른 하나가 늘어나는 상충 관계의 존재

## 슬라이드 19: 오차의 분해: 편향, 분산, 그리고 노이즈
- 공식: 총 오차 = 편향^2 + 분산 + 줄일 수 없는 오차(Noise)
- 목표: 모델 복잡도를 조절하여 총 오차가 최소가 되는 최적의 스위트 스팟 포착
- 결론: 머신러닝의 모든 기법은 결국 이 트레이드오프를 극복하기 위한 수단

## 슬라이드 20: 결론: 통찰을 위한 진화하는 도구
- ML의 성격: 절대적 정답이 아닌, 데이터 통찰을 얻기 위한 가변적 도구
- 학습의 자세: 기술의 역사와 수학적 원리를 이해하고 나만의 결론을 도출할 것
- 메시지: 도구를 섬기지 말고, 데이터를 꿰뚫는 주인이 될 것
