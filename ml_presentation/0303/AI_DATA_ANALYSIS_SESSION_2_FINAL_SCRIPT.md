# AI DATA ANALYSIS: SESSION 2 최종 원고
## 주제: 트리 모델과 앙상블의 지혜

## 슬라이드 0: 강의 개요
- 학회: Parrot
- 강의 주제: 트리 모델과 앙상블의 진화
- 강의자: 엄태준

## 슬라이드 1: 의사결정 나무의 직관
- 원리: 스무고개 방식의 데이터 분할 프로세스
- 특징: 복잡한 현상을 단순한 질문들로 해체
- 목표: 데이터를 가장 순수하게 가르는 경계 탐색

## 슬라이드 2: 분할의 기준: 지니 계수와 엔트로피
- 이유: 어떤 질문이 가장 효율적인지 수치로 판단
- 지니 계수: 집단의 불순도를 측정하는 지표
- 엔트로피: 정보의 무질서도를 나타내는 척도

## 슬라이드 3: 나무 모델의 강점: 투명성
- 특징: 판단의 근거를 시각적으로 확인 가능
- 가치: 로직의 흐름이 명확하여 비즈니스 설득에 유리
- 차별점: 블랙박스가 아닌 화이트박스 모델의 표본

## 슬라이드 4: 단일 나무의 치명적 한계
- 문제: 데이터의 미세한 변화에도 구조가 급변함
- 현상: 훈련 데이터에만 완벽히 특화되는 경향
- 결과: 새로운 데이터에 대한 예측 안정성 결여

## 슬라이드 5: 이론적 배경: 편향과 분산
- 편향: 모델의 가정 자체가 틀려서 발생하는 오차
- 분산: 데이터 변화에 모델이 민감하게 반응하는 정도
- 핵심: 모델의 오차는 이 두 요소의 합으로 구성됨

## 슬라이드 6: 바이어스-베리언스 트레이드오프
- 역설: 편향을 줄이면 분산이 늘고, 분산을 줄이면 편향이 늠
- 목표: 두 오차의 합이 최소가 되는 최적의 지점 탐색
- 해결: 단일 모델의 한계를 넘기 위한 방법론의 필요성

## 슬라이드 7: 트레이드오프 그래프의 해석
- 단순 모델: 높은 편향, 낮은 분산
- 복잡 모델: 낮은 편향, 높은 분산
- 정답: 모델이 복잡해질 때 튀어오르는 분산을 잡는 기술

## 슬라이드 8: 집단 지성의 활용: 앙상블
- 철학: 하나의 천재보다 수천 명의 평범한 이들의 결합
- 방식: 여러 개의 약한 모델을 하나로 묶어 성능 극대화
- 전략: 개별 모델의 약점을 서로 보완하며 견고함 유지

## 슬라이드 9: 앙상블의 두 줄기: 배깅과 부스팅
- 구분: 모델을 병렬로 결합하는가, 순차로 결합하는가
- 배깅: 분산을 줄여 안정성을 높이는 데 주력
- 부스팅: 편향을 줄여 정확도를 높이는 데 주력

## 슬라이드 10: 방법론 1: 배깅의 원리
- 핵심: 부트스트랩 샘플링을 통한 데이터 다양성 확보
- 과정: 중복을 허용한 무작위 샘플 추출 및 독립 학습
- 목표: 각 나무들이 서로 다른 데이터의 단면을 학습

## 슬라이드 11: 배깅의 병렬 학습과 투표
- 방식: 수많은 나무를 동시에 학습시킨 후 결과 집계
- 회귀: 개별 나무 예측값의 산술 평균 사용
- 분류: 다수결 원칙에 따른 최종 클래스 결정

## 슬라이드 12: 배깅의 정점: 랜덤 포레스트
- 혁신: 데이터뿐만 아니라 변수도 무작위 선택
- 효과: 나무들 간의 상관관계를 낮춰 독립성 극대화
- 특징: 앙상블 모델 중 가장 대중적이고 안정적인 도구

## 슬라이드 13: 배깅의 마법: 분산 억제
- 이유: 개별 나무의 과격한 변동을 평균화로 상쇄
- 결과: 과적합 방지에 탁월하며 실전 데이터에 강함
- 이유: 수학적으로 평균은 개별 관측치보다 분산이 낮음

## 슬라이드 14: 방법론 2: 부스팅의 원리
- 핵심: 이전 모델의 실수를 다음 모델이 이어받아 교정
- 과정: 오답 데이터에 가중치를 부여하여 순차적 학습
- 목표: 모델이 풀기 어려워하는 데이터에 집중 공격

## 슬라이드 15: 부스팅의 순차 학습 메커니즘
- 방식: 오차(Residual)가 큰 영역을 집중적으로 학습
- 가중치: 틀린 샘플은 더 크게, 맞춘 샘플은 더 작게 처리
- 진화: 반복을 거듭할수록 오차가 0에 수렴하는 구조

## 슬라이드 16: 부스팅의 마법: 편향 제거
- 이유: 모델이 지속적으로 오차를 줄여나가며 정교해짐
- 효과: 단순한 모델들을 모아 압도적인 정확도 달성
- 이유: 학습을 반복할수록 전체 모델의 표현력이 향상됨

## 슬라이드 17: 비교 분석: 배깅 vs 부스팅
- 속도: 병렬 학습인 배깅이 순차 학습인 부스팅보다 빠름
- 성능: 하이퍼파라미터 최적화 시 부스팅이 일반적으로 우수
- 안정성: 배깅은 과적합에 강하고, 부스팅은 과적합 위험 존재

## 슬라이드 18: 피처 임포턴스: 판단의 근거
- 의미: 수만 번의 분할 중 어떤 변수가 가장 기여했는가
- 지표: 불순도 감소량이나 평균 정확도 기여도로 측정
- 한계: 상관관계가 높은 변수 간에는 기여도가 왜곡될 수 있음

## 슬라이드 19: 결론: 도구의 조화로운 사용
- 성격: 배깅과 부스팅은 상황에 따라 골라 쓰는 무기
- 학습: 각 기법의 수학적 원리를 이해하고 한계점 인식
- 메시지: 데이터의 특성에 맞춰 최적의 앙상블 전략을 수립할 것
