# AI DATA ANALYSIS: SESSION 1 최종 원고
## 주제: 머신러닝의 철학과 여정

## 슬라이드 0: 강의 개요
- 학회: Parrot
- 강의 주제: ML
- 강의자: 엄태준

## 슬라이드 1: 상관관계 ≠ 인과관계
- 현상: 무릎 통증 발생 시 비가 온다는 상관성
- 오류: 무릎 통증이 비를 부르는 것은 아님
- 핵심: 상관성 속에서 잘못된 원인을 짚는 위험성 경계

## 슬라이드 2: 가설 설정과 실험 검증
- 프로세스: 관찰 → 가설 → 실험 → 인과 규명
- 데이터 증명: 실험군과 대조군 비교를 통한 효과 검증
- 이유: 기전을 몰라도 실험적 검증으로 인과 인정

## 슬라이드 3: 분석의 본질: 예측과 설득
- 목적 1: 보이지 않는 미래를 숫자로 맞추는 예측
- 목적 2: 데이터 기반으로 타인을 움직이는 설득
- 분석: 상관성을 인과성으로 좁혀가는 설득의 무기

## 슬라이드 4: 통계학의 철학: 인과 규명
- 핵심: 현상의 배후에 있는 인과 구조의 파악
- 방법: 샘플 추출을 통한 모집단의 모수 추정
- 가치: 결과의 신뢰성과 수식적 증명에 대한 집착

## 슬라이드 5: 분석의 시작: 선형회귀
- 수식: y = ax + b
- 의미: 독립변수와 종속변수 사이의 선형 관계 모델링
- 이유: 단순하지만 강력한 해석력과 예측의 기초 제공

## 슬라이드 6: 통계학의 한계: 다중공선성
- 문제: 독립변수 간 강한 상관성으로 인한 원인 식별 불가
- 수식 오류: 회귀 계수의 분산 폭주로 인한 신뢰성 상실
- 결과: 어떤 변수가 진짜 인과적 기여를 하는지 판단 불가

## 슬라이드 7: 통계학의 한계: 차원의 저주
- 현상: 변수가 늘어날수록 데이터가 공간에서 희소해짐
- 영향: 샘플 간 거리가 멀어져 패턴 학습 불가능
- 한계: 데이터 폭발 시대에 고전적 방식이 작동하지 않는 이유

## 슬라이드 8: 머신러닝의 시대적 등장 배경
- 데이터: 인터넷과 센서 보급으로 인한 데이터 폭발적 증가
- 하드웨어: GPU 등 대규모 병렬 연산이 가능한 컴퓨팅 파워
- 복잡성: 기존 통계로 풀 수 없는 비선형 문제의 증대
- 수요: 수작업 규칙이 아닌 데이터 기반 자동화 필요성

## 슬라이드 9: 머신러닝의 정의와 핵심 기전
- 정의: 데이터로부터 기계가 스스로 규칙을 학습하는 기술
- 방식: 명시적 프로그래밍 없이 데이터 기반으로 모델 구축
- 핵심: 방대한 데이터 속 숨겨진 패턴의 자동 추출
- 가치: 경험적 증거를 바탕으로 한 지능적 판단 수행

## 슬라이드 10: 머신러닝 패러다임: 예측 최우선
- 철학: 설명하지 못해도 좋으니 정확하게 적중
- 전략: 복잡한 연산과 계산 부하를 감수하고 정확도 극대화
- 전환: 인과 구조 규명에서 결과 예측 최우선으로 이동

## 슬라이드 11: 과적합: 정확도의 독배
- 현상: 훈련 데이터는 완벽히 암기하나 실전 예측은 실패
- 원인: 데이터 내 노이즈까지 모델이 학습해버린 결과
- 결론: 일반화 능력이 없는 모델은 가치 상실

## 슬라이드 12: 모델 복잡도와 예측력의 역설 (1/2)
- 단순 모델: 설명력은 낮으나 새로운 데이터 예측에 강함
- 복잡 모델: 기존 데이터는 완벽히 맞추나 실전력 급감
- 핵심: 학습 오차와 실전 오차 사이의 최적점 탐색

## 슬라이드 13: 모델 복잡도와 예측력의 역설 (2/2)
- 현상: 모델이 복잡해질수록 훈련 오차는 지속 감소
- 반전: 특정 시점부터 검증 오차는 다시 상승
- 목표: 오차가 다시 튀어오르기 전의 스위트 스팟 포착

## 슬라이드 14: 모델 선택 지표: AIC & BIC
- 이유: 모델이 복잡할수록 패널티 부과하여 최적화
- AIC: 모델의 적합도와 복잡도 사이의 균형점 탐색
- BIC: 표본이 클수록 변수 개수를 더욱 엄격하게 제한

## 슬라이드 15: 정규화: Ridge & Lasso
- 이유: 가중치 크기를 강제로 억제하여 과적합 방지
- Ridge: 모든 가중치를 골고루 작게 유지
- Lasso: 불필요한 변수의 가중치를 0으로 만들어 자동 제거

## 슬라이드 16: 차원 축소: PCA
- 이유: 정보 손실을 최소화하며 데이터 차원 압축
- 핵심: 데이터 분산이 가장 큰 새로운 축 추출
- 효과: 노이즈 제거 및 고차원 데이터의 효율적 분석

## 슬라이드 17: 나만의 결론을 위한 여정
- 성격: 정답이 아닌 통찰을 얻기 위한 도구
- 학습: 기술의 역사를 이해하고 나만의 분석 관점 정립
- 메시지: 도구에 휘둘리지 말고 데이터를 꿰뚫는 주인이 될 것
