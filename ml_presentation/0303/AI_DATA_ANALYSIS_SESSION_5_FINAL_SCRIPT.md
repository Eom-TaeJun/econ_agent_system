# AI DATA ANALYSIS: SESSION 5 최종 원고
## 주제: 설명 가능한 AI와 설득의 기술

## 슬라이드 0: 강의 개요
- 학회: Parrot
- 강의 주제: XAI와 SHAP를 활용한 해석
- 강의자: 엄태준

## 슬라이드 1: 성능 뒤에 숨겨진 공포: 블랙박스
- 현상: 모델 성능은 완벽하지만 왜 그런 판단을 했는지 모름
- 리스크: 편향된 데이터 학습으로 인한 윤리적·사회적 비난
- 문제: 실무자가 모델의 결과를 신뢰하고 실행에 옮기지 못함

## 슬라이드 2: 설명 가능한 AI (XAI)의 등장
- 정의: AI의 판단 근거를 사람이 이해할 수 있는 언어로 번역
- 필요성: 규제가 강한 금융·의료·법률 분야의 필수 요건
- 목적: 예측 정확도와 설명 가능성 사이의 가교 역할

## 슬라이드 3: XAI의 역사와 철학
- 과거: 단순하지만 설명력이 높은 선형 모델 중심
- 현재: 복잡하지만 설명력이 낮은 딥러닝·앙상블 모델 중심
- 미래: 성능을 유지하면서 내부를 들여다보는 해석 기술 결합

## 슬라이드 4: 해석의 두 층위: 글로벌 vs 로컬
- 글로벌: 모델 전체가 전반적으로 어떤 변수를 중요하게 보는가
- 로컬: 왜 이 특정한 샘플에 대해 이런 예측을 내놓았는가
- 가치: 전체적 경향 파악과 개별 고객 대응의 동시 만족

## 슬라이드 5: 블랙박스를 여는 열쇠: SHAP
- 배경: 노벨 경제학상을 받은 게임 이론의 샤플리 값 차용
- 개념: 여러 변수가 협력하여 만든 예측치 분배
- 강점: 수학적으로 가장 견고한 변수 기여도 산출 방식

## 슬라이드 6: SHAP의 수학적 Why: 공정한 기여도
- 원리: 특정 변수가 있을 때와 없을 때의 예측치 차이 계산
- 특징: 모든 가능한 변수 조합을 고려하여 공정하게 가중치 배분
- 결과: 각 변수가 예측값을 위로, 아래로 얼마나 밀었는지 산출

## 슬라이드 7: 시각화의 정점: 워터폴 차트
- 구성: 기본 기대치에서 시작해 변수별 기여도가 쌓이는 계단형 차트
- 해석: 빨간색은 예측값 상승 기여, 파란색은 하락 기여
- 효과: 복잡한 수식을 초등학생도 이해할 수 있는 시각 언어로 치환

## 슬라이드 8: 설득의 무기: SHAP 활용법
- 사례: 이 고객의 대출 거절 이유는 연체 이력 때문입니다
- 대응: 단순 통보가 아닌 근거 제시를 통한 고객 납득 및 CS 방어
- 가치: 모델의 예측을 비즈니스 행동으로 바꾸는 결정적 트리거

## 슬라이드 9: SHAP 사용 시 주의사항
- 한계: 변수 간 상관관계가 매우 높으면 기여도가 왜곡됨
- 주의: SHAP 값은 인과관계가 아닌 모델 내부의 기여도일 뿐임
- 당부: 도메인 지식을 바탕으로 산출된 기여도의 타당성 상시 검토

## 슬라이드 10: 머신러닝 모델러의 진짜 역할
- 정의: 숫자와 비즈니스 언어 사이를 연결하는 통역관
- 임무: 모델의 폭주를 막는 문지기이자 성과를 입증하는 전도사
- 기술: 수학적 실력만큼 중요한 데이터 기반의 스토리텔링 역량

## 슬라이드 11: 에이전틱 AI 시대로의 로드맵
- 미래: AI가 직접 판단하고 행동하는 자율 행동의 시대
- 핵심: 에이전트의 모든 결정 밑바탕에는 우리가 배운 ML 모델 존재
- 준비: 예측 모듈과 해석 모듈을 자유자재로 호출하는 설계 능력

## 슬라이드 12: 5주간의 여정 요약

- 4~5차시: 정밀한 평가와 데이터 기반 설득의 미학
