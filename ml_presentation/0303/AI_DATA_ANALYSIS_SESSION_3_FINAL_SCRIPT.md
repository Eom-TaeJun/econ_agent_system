# AI DATA ANALYSIS: SESSION 3 최종 원고
## 주제: 부스팅의 정점과 하이퍼파라미터

## 슬라이드 0: 강의 개요
- 학회: Parrot
- 강의 주제: XGBoost와 부스팅 최적화
- 강의자: 엄태준

## 슬라이드 1: 부스팅의 수학적 기초: 잔차 학습
- 원리: 실제값과 예측값의 차이인 잔차를 줄이는 과정
- 목표: 매 단계마다 모델이 잔차를 새로운 타겟으로 학습
- 결과: 단계를 거듭할수록 예측값이 실제값에 수렴

## 슬라이드 2: 경사 하강법과 부스팅의 결합
- 혁신: 손실 함수를 최소화하는 방향으로 모델 업데이트
- 수학적 Why: 잔차를 줄이기 위해 기울기(Gradient) 활용
- 특징: 미분 가능한 모든 손실 함수에 적용 가능한 범용성

## 슬라이드 3: 현대 ML의 주역: XGBoost의 등장
- 배경: 기존 GBM의 느린 속도와 과적합 문제를 해결
- 명성: 데이터 사이언스 대회 우승자들의 필수 도구
- 가치: 정형 데이터 분석에서 가장 강력한 성능 발휘

## 슬라이드 4: XGBoost의 핵심: 테일러 전개
- 수학적 Why: 2차 미분항을 활용해 손실 함수를 정밀 근사
- 효과: 더 빠르고 정확하게 최적의 분할 지점 탐색
- 차별점: 기존의 1차 미분만 쓰던 방식보다 월등한 수렴 속도

## 슬라이드 5: 과적합 방지: 자체 정규화 기능
- 특징: 모델 수식 내에 정규화 항(L1, L2)을 직접 포함
- 효과: 나무의 복잡도를 스스로 제어하며 일반화 성능 강화
- 가치: 별도의 복잡한 처리 없이도 과적합에 강한 모델 구축

## 슬라이드 6: 하드웨어 최적화: 병렬 처리
- 혁신: 데이터 정렬 및 분할 지점 탐색의 병렬화
- 속도: CPU 코어를 최대한 활용하여 학습 시간 단축
- 기술: 캐시 최적화와 메모리 관리 기법의 집약체

## 슬라이드 7: 결측치 처리의 자동화
- 지능: 학습 과정에서 결측치가 갈 최적의 방향을 스스로 결정
- 편의: 데이터 전처리 단계에서의 번거로움 대폭 감소
- 효과: 실제 데이터의 불완전함에 대응하는 강력한 회복력

## 슬라이드 8: 하이퍼파라미터: 모델의 조절자
- 정의: 학습 시작 전 사람이 직접 설정해주는 변수
- 중요성: 설정값에 따라 모델의 성능이 천차만별로 변화
- 자세: 도구를 정교하게 다루기 위한 운전대 조작과 같음

## 슬라이드 9: 핵심 파라미터 1: 학습률
- 역할: 각 단계 모델의 기여도를 얼마나 반영할지 결정
- 전략: 낮을수록 꼼꼼히 학습하지만 학습 시간이 길어짐
- 조언: 일반적으로 낮은 학습률과 많은 나무 개수를 조합

## 슬라이드 10: 핵심 파라미터 2: 나무의 깊이
- 역할: 개별 의사결정 나무가 얼마나 복잡해질지 제한
- 영향: 깊을수록 복잡한 패턴을 잡지만 과적합 위험 상승
- 조언: 비즈니스 복잡도에 따라 3~10 사이에서 최적점 탐색

## 슬라이드 11: 핵심 파라미터 3: 샘플링 비율
- 행 샘플링: 각 나무 학습 시 데이터의 일부만 무작위 사용
- 열 샘플링: 분할 시 변수의 일부만 무작위 사용
- 효과: 나무들 간의 다양성을 높여 일반화 성능 극대화

## 슬라이드 12: 최적의 조합 찾기: 그리드 서치
- 방식: 가능한 모든 파라미터 조합을 전수 조사
- 단점: 조합이 많아질수록 연산 시간이 기하급수적 증가
- 특징: 확실하지만 가장 무거운 최적화 방법론

## 슬라이드 13: 효율적인 탐색: 랜덤 서치
- 방식: 정해진 범위 내에서 무작위로 조합을 골라 테스트
- 장점: 그리드 서치보다 빠르면서도 유사한 성능 확보
- 특징: 넓은 탐색 공간에서 효율적으로 최적 지점 근사

## 슬라이드 14: 차세대 엔진: LightGBM 소개
- 특징: 리프 중심 분할 방식으로 XGBoost보다 빠른 속도
- 혁신: 대용량 데이터에서 메모리 사용량 획기적 절감
- 비교: 정확도는 유지하면서 학습 속도는 비약적으로 향상

## 슬라이드 15: 도구의 선택 기준
- XGBoost: 중간 규모 데이터에서의 안정성과 정밀함
- LightGBM: 대규모 데이터셋에서의 압도적인 처리 속도
- 메시지: 데이터의 크기와 자원에 따른 유연한 도구 선택

## 슬라이드 16: 하이퍼파라미터 튜닝의 철학
- 경계: 파라미터 수정만으로 데이터의 본질적 한계 극복 불가
- 우선순위: 전처리와 특징 공학이 튜닝보다 항상 중요함
- 결론: 튜닝은 마지막 1~2%의 성능을 쥐어짜는 화룡점정

## 슬라이드 17: 요약: 부스팅을 지배하는 법
- 원리: 잔차를 줄이는 순차적 노력의 집합
- 기술: 수학적 근사와 하드웨어 성능의 결합
- 태도: 파라미터를 조절하며 모델의 반응을 살피는 실험 정신
