# AI DATA ANALYSIS: SESSION 4 최종 원고
## 주제: 모델 평가와 실전의 스위트 스팟

## 슬라이드 0: 강의 개요
- 학회: Parrot
- 강의 주제: 성능 평가 지표와 모델 검증
- 강의자: 엄태준

## 슬라이드 1: 예측 이후의 질문: 잘 만들었는가?
- 상황: 모델 생성 후 실제 현장 투입 전 필수 단계
- 목적: 모델의 신뢰성을 숫자로 입증하고 리스크 파악
- 핵심: 비즈니스 목적에 부합하는 평가 척도의 설정

## 슬라이드 2: 정확도의 함정
- 현상: 99%의 데이터가 정상인 경우, 무조건 정상이라 해도 정확도 99%
- 문제: 우리가 정작 찾고 싶은 1%의 이상치를 놓칠 수 있음
- 결론: 데이터 불균형 상황에서 정확도는 최악의 지표

## 슬라이드 3: 판단의 지도: 오차 행렬
- 구성: 실제 정답과 모델 예측의 조합으로 만든 2x2 매트릭스
- 4요소: 정탐지, 미탐지, 오탐지, 정상탐지
- 가치: 모델이 어떤 종류의 실수를 저지르는지 한눈에 파악

## 슬라이드 4: 정밀도: 모델의 확신
- 정의: 모델이 긍정이라 예측한 것 중 실제 긍정인 비율
- 의미: 모델이 맞다고 한 말 중에 진짜가 얼마나 있는가?
- 상황: 오탐지의 비용이 매우 큰 경우에 핵심 지표로 사용

## 슬라이드 5: 재현율: 놓치지 않는 능력
- 정의: 실제 긍정인 것들 중 모델이 긍정이라 맞춘 비율
- 의미: 우리가 찾아야 할 대상 중 얼마나 검출해냈는가?
- 상황: 미탐지의 결과가 치명적인 경우에 가장 중요한 지표

## 슬라이드 6: 정밀도 vs 재현율 트레이드오프
- 역설: 하나를 높이려 하면 다른 하나가 낮아지는 관계
- 원인: 판단 기준(임계값)을 엄격하게 하느냐 느슨하게 하느냐의 차이
- 목표: 두 지표 사이에서 비즈니스 최적의 균형점 탐색

## 슬라이드 7: 조화로운 지표: F1 스코어
- 정의: 정밀도와 재현율의 조화 평균
- 가치: 어느 한쪽으로 치우치지 않는 모델의 종합 성능 측정
- 이유: 산술 평균보다 낮은 값에 민감하여 불균형 성능 반영

## 슬라이드 8: 비즈니스 예시 1: 암 진단 모델
- 우선순위: 재현율 극대화 (환자를 놓치면 생명 위험)
- 허용: 정밀도가 낮아져 발생하는 재검사 비용은 감수 가능
- 전략: 판단 임계값을 낮추어 조금이라도 의심되면 양성 판정

## 슬라이드 9: 비즈니스 예시 2: 스팸 메일 필터
- 우선순위: 정밀도 극대화 (중요 메일을 스팸 처리하면 안 됨)
- 허용: 재현율이 낮아져 스팸을 몇 개 놓치는 것은 큰 문제 없음
- 전략: 판단 임계값을 높여 아주 확실한 경우만 스팸 처리

## 슬라이드 10: 판단의 기준선: 임계값 조정
- 원리: 모델이 출력하는 0~1 사이 확률값의 절단 지점 설정
- 기본값: 보통 0.5를 기준으로 사용하나 이는 절대적이지 않음
- 활용: 임계값을 움직이며 정밀도와 재현율의 비중 조절

## 슬라이드 11: 모든 임계값에서의 성능: AUC-ROC
- 정의: 임계값을 0에서 1까지 변화시킬 때의 모델 성능 곡선
- AUC: 곡선 아래의 면적 (1에 가까울수록 완벽한 모델)
- 장점: 임계값 설정과 무관하게 모델 자체의 분류 잠재력 평가

## 슬라이드 12: 회귀 모델의 평가 지표: MSE & RMSE
- MSE: 실제값과 예측값 차이의 제곱 평균
- RMSE: MSE에 루트를 씌워 실제 단위와 맞춘 지표
- 특징: 큰 오차에 대해 더 강한 패널티를 부여함

## 슬라이드 13: 직관적인 회귀 지표: MAE
- 정의: 오차의 절대값에 대한 평균
- 장점: 에러의 크기가 실제 단위와 일치하여 해석이 매우 쉬움
- 비교: 이상치에 덜 민감하여 모델의 일반적 성능 파악에 유리

## 슬라이드 14: 모델의 설명력: R-Square
- 의미: 모델이 데이터의 분산을 얼마나 설명하고 있는가
- 범위: 0에서 1 사이 (1에 가까울수록 설명력이 높음)
- 주의: 데이터 특성에 따라 0.3도 높을 수 있고 0.9도 낮을 수 있음

## 슬라이드 15: 실전 검증: 교차 검증
- 문제: 특정 테스트 데이터에만 우연히 잘 맞는 운을 배제
- 방식: 데이터를 여러 조각으로 나눠 번갈아가며 학습과 검증
- 가치: 모델의 실제 운영 시 예상 성능을 가장 안정적으로 추정

## 슬라이드 16: 비즈니스 스위트 스팟 찾기
- 철학: 수학적 최적점과 비즈니스 최적점은 다를 수 있음
- 분석: 오탐 비용과 미탐 비용을 금액으로 환산하여 의사결정
- 결론: 숫자를 넘어 비용과 가치를 고려한 최종 모델 확정
